## 1. 研究问题

S7.0不训练预测模型，而是先回答：

> 如果系统能够准确知道接收端何时发生静默上下文重置，是否存在足够大的 clean–bit 改善空间，使后续风险预测研究值得继续？

固定基线对全部 N 使用10景静默心跳。预言机直接读取仿真的真实重置流，并在重置发生的同一景触发上下文探测。二者共享相同的频谱、码本、任务更新、丢包、ACK丢失、延迟重复、激活回退、精确escape和总 bit 计费。

预言机是非因果理论上界，不是可部署算法。它只能用于判断研究空间，不能作为阶段7最终方法。

## 3. 多步风险标签

任务风险表示：当前动作在未来 h 景内的最大 regret 是否超过0.2 dB。

上下文风险表示：未来 h 景内是否发生接收端静默重置。

联合风险在任务风险或上下文风险任一发生时取1。

| N | h = 1任务风险 | h = 1上下文风险 | h = 1联合风险 | h = 10任务风险 | h = 10上下文风险 | h = 10联合风险 |
|---:|---:|---:|---:|---:|---:|---:|
| 8 | 10.37% | 1.99% | 12.16% | 27.71% | 18.21% | 40.93% |
| 16 | 10.03% | 1.99% | 11.83% | 27.72% | 18.29% | 40.95% |
| 32 | 12.42% | 1.99% | 14.17% | 32.53% | 18.20% | 44.73% |
| 64 | 10.70% | 2.01% | 12.49% | 29.40% | 18.38% | 42.41% |

结果说明风险不是极端稀有事件。一步任务风险约10%—12%，十步联合风险约41%—45%，适合开展多时间范围风险排序和生存分析。模型评测必须同时报告正样本率，不能只报告准确率。

表中的“配对bit降幅”先在每个站点、每条共同随机轨迹内计算百分比，再进行分层汇总，因此不等于“两个总体平均bit之差除以固定平均bit”。

四种 N 均满足：

- clean增益95%区间下界超过1个百分点；
- 总bit降幅95%区间下界超过5%；
- 错误码本动作执行次数为0。

预注册要求为至少3/4种 N 通过，实际为4/4通过，因此 S7.0 预言机收益空间门槛成立。

## 5. 收益来源与异质性

固定10景的心跳bit约为2.59—2.99 bit/景，预言机降至0.43—0.50 bit/景。恢复bit也由约3.36—4.74降至2.57—3.80 bit/景。说明上界收益同时来自：

1. 删除低风险时期的大量周期探测；
2. 在真实重置发生时立即发现上下文丢失；
3. 减少延迟发现导致的后续恢复与重复开销。

但收益并非每站点完全一致：

- clean增益为正的站点数分别为28、26、26、24，与各 N 的解析语义站点数一致；
- 未解析站点采用精确回退，预言机没有收益，也没有被删除；
- 少数解析站点的预言机bit点估计略高于固定心跳，最差约增加1.87%—3.51%；
- 因此阶段7不能简单采用“每次预测到风险就立即探测”，必须学习单位新增bit能够避免多少失效，并保留预算约束。

---

## 6. 决策

S7.0的正确结论是：

> 固定心跳的主要可靠性缺口确实存在可利用的风险时序结构，且在完整协议计费下具有足够大的理论改善空间，值得进入因果风险模型研究。

本结果不证明：

- 真实模型可以获得20%—26%的bit降幅；
- 发送端能够准确知道接收端重置；
- 阶段7算法已经完成；
- 这些已见站点可以承担阶段7 Final。

下一步进入 S7.1，依次建立固定10景、状态年龄阈值、Persistence和一阶Markov强基线，并构造仅使用发送端历史的因果特征。只有基线通过跨站点预测、校准和闭环门槛，才进入逻辑回归、离散生存模型与梯度提升树。

## 7. 统计解释与谬误扫描

总体置信等级：`CAUTION`。原因不是效应不足，而是预言机具有非因果信息，且34个站点全部属于已见开发数据。

覆盖：11/11类统计与方法谬误已检查。

| 谬误 | 严重度 | 检查结论 |
|---|:---:|---|
| Simpson悖论 | NOTE | 总体clean方向为正，所有解析站点也为正；bit在少数站点为负，存在异质性但未见总体与全部子组方向反转 |
| 生态谬误 | CAUTION | 分析单位是站点和仿真轨迹，不能推断单架真实无人机的个体性能 |
| Berkson偏差 | CAUTION | 样本来自满足结构要求的FM站点，不能代表全部频段、设备和移动环境 |
| 碰撞变量偏差 | NOTE | 未按预言机结果删除站点；解析失败站点保留精确回退，降低了结果后筛选风险 |
| 基准率忽视 | NOTE | 已报告每个 N、每个时间范围的任务、上下文和联合正样本率 |
| 均值回归 | NOTE | 站点并非按极端阶段6结果选择，比较使用同一批站点与共同随机轨迹 |
| 幸存者偏差 | NOTE | 34个站点全部保留，未解析站点没有被排除于系统汇总 |
| 多重比较/遍历效应 | CAUTION | 四种 N 和四个时间范围已预注册，但次要分项较多，不能把每个区间解释为独立确认性发现 |
| 分析路径分叉 | CAUTION | 协议在完整运行前冻结；单站点smoke只修复了标签分母重复计数，未根据效果修改算法或门槛 |
| 相关代替因果 | CAUTION | 配对差异可解释为受控仿真中的策略效应，不能外推为真实无线部署因果结论 |
| 反向因果 | NOTE | 标签时间顺序明确；预言机读取未来/隐藏重置仅作为上界，未伪装成因果预测器 |
