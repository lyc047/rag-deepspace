# C1-v4 任务充分块语义与零比特时间回退：开发结果报告

> 日期：2026-07-22  
> 性质：两次完整披露的开发实验，不是新的 Final  
> 核心结论：块代价/最优块语义显著优于 occupancy 代理；最近成功块回退在不增加bit时进一步改善平均和尾部 regret

## 1. 从 C1-v3 失败到 C1-v4

C1-v3 的问题不是神经网络容量不足，而是训练目标和真实资源任务错配：occupancy 只保留“超过阈值的频点比例”，最终调度却需要比较连续块的平均 dBm。C1-v4 将发送对象改为接收端执行资源选择真正需要的统计量。

设8个信道功率为 p₁，p₂，…，p₈，需求为连续4信道，则5个候选块代价为：

> **候选块代价：** cⱼ = (pⱼ + pⱼ₊₁ + pⱼ₊₂ + pⱼ₊₃) ÷ 4，其中 j = 1，2，…，5。

对于固定需求、当前扫频和单站点选择，代价向量 c = (c₁，c₂，…，c₅) 是比8维occupancy更直接的任务语义，而最优块 j* = arg minⱼ cⱼ 是该单一决策的充分统计量。

## 2. 第一轮：冻结表示比较

### 2.1 数据与治理

开发数据按整日分隔：2月8–9日270景训练预留、2月10日180景校准、2月11日180景验证，三个站点各占三分之一。每站先做15分钟稀疏化；20个 pilot、原三站 Final 的全部 provenance、C1-v3的60景校准与300景确认来源全部排除。既有 holdout 测量值和指标均未加载。

五种表示在查看验证结果前冻结，统一使用152-bit版本化头部/质量兼容开销，并通过相同的 CRC、Hamming(7,4)、调制、三种信道、四档Eb/N0和有限重传链路。

## 3. 为什么没有增加学习型校正器

`block_score_fixed4` 的 clean regret 只有0.000594 dB，`best_block_indicator1` 为0。此时继续训练网络最多拟合极小的量化残差，无法修复 CRC 检出的整包失败。学习型模型会增加参数、训练选择自由度和过拟合风险，却没有与之匹配的剩余映射误差，因此按计划取消。

第一轮中约32%的最终帧未交付，链路失败成为主导误差。下一步应改进失败后的决策可靠性，而不是增加前端网络复杂度。

## 4. 第二轮：零比特最近成功块回退

### 4.1 冻结设计

在查看2月12日数据前冻结两种接收端策略：

- 基线：157-bit最优块指示包失败时固定选择 block start 0；
- 提议：相同报文、相同链路轨迹、相同发送bit；失败时使用同一站点、同一链路条件流中最近一次成功解码的块，若不存在历史才选择0。

这是一种接收端状态语义，额外通信bit为0，状态复杂度为每站点保存一个块索引。新验证集为2月12日180景，仍是每站60景、15分钟稀疏化，与第一轮验证日期完全分离。

### 4.2 结果

| 方法 | 平均 regret / dB | CVaR0.9 / dB | 实际发送bit | 帧成功率 |
|---|---:|---:|---:|---:|
| 固定 block-0 回退 | 0.173469 | 0.669129 | 692.558 | 0.678426 |
| 最近成功块回退 | 0.124060 | 0.418094 | 692.558 | 0.678426 |

平均 regret 降低28.48%，CVaR降低37.52%，实际bit和链路成功轨迹严格相同。10,000次、72个小时块的统计结果：

- 平均regret差：−0.049409 dB，单侧95%上界−0.029334，经验单侧p值 = 9.999 × 10⁻⁵；
- CVaR差：−0.251035 dB，单侧95%上界−0.175251，经验单侧p值 = 9.999 × 10⁻⁵；
- 实际bit差及上界均为0。

三个站点方向一致：CC1由0.149589降至0.117631，CC2由0.299167降至0.188746，LW1由0.071651降至0.065803。

## 5. 当前可主张的创新点

当前 C1-v4 形成两个相互配合、但必须保持开发证据措辞的创新点：

1. **任务充分连续块语义**：由8维阈值 occupancy 转为5维连续块功率代价/最优块决策，在真实数字包成本下联合降低 regret、尾部风险和发送bit。
2. **零比特状态语义回退**：把最近成功资源决策作为接收端状态，在不改变报文、信道轨迹和bit的条件下保护包失败场景，重点改善 CVaR。

其计算复杂度很低：块代价为 O(ND) 的滑动聚合；最优块搜索为 O(N−D+1)；回退状态为每站点一个索引，更新和查询均为 O(1)。贡献价值来自任务建模、通信闭环和可靠统计，而不是人为增加模型参数。

## 6. 局限与下一步

- 当前最优块语义依赖固定需求4信道；多需求、多节点融合或二次规划应使用 `block_score_fixed4` 或扩展代价语义。
- 最近成功回退依赖频谱的时间相关性；高速移动、长时间失联和突变干扰下必须加入 age/变化检测和最大陈旧时间。
- 数据来自同一 AERPAW 2022-02 固定站点活动，报告链路仍为仿真；不是新采集、无人机移动、MIMO或实测回传。
- 第一轮和第二轮都是开发结果。正式论文正结论仍需要另一公开数据集或新采集批次进行一次冻结确认。

下一算法步骤应是只在开发数据上冻结“最大陈旧时间/变化触发失效”规则，然后寻找新数据确认；不得再回看2月11或2月12结果反复调阈值。
