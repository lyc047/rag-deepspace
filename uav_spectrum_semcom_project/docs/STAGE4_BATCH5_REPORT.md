## 1. 问题与控制变量

Batch 4 的一步 oracle 空间很大，但当前价值网络不能稳定超过 SNR 和阶段 3 先验。主要怀疑是 1-bit G1 隐藏了候选节点的细粒度概率。由于阶段 4 协议本来允许 G1 使用 1—2 bit/子信道，本批仅把 G1 概率量化从 1 bit 改为 2 bit，其余全部保持不变：C1 checkpoint、scene、节点扰动、G2/G3、反事实标签、链路、网络结构、种子和统计规则。

在重训网络前先检查两个必要条件：2-bit 预览本身是否形成显著收益—成本优势，以及它是否增加而非压缩可学习的升级价值。未通过时禁止继续五种子训练。

## 3. 配对收益—成本结果

| G1 | regret | 预览期望 bit | clean rate | Brier | 一步 oracle regret |

| q1 | 0.028172 | 1634.46 | 0.4800 | 0.008060 | 0.005500 |

validation 的 q2−q1 配对结果为：

- regret `−0.001576`，95% CI `[−0.005901, 0.002615]`，不显著；
- 预览成本 `+75.146 bit`，确定增加；
- clean rate 差为 0，95% CI `[-0.0733, 0.0733]`；
- Brier `+0.008995`，95% CI `[0.007629, 0.010311]`，显著恶化；
- oracle 可减少 regret 的能力下降 `−0.012376`，95% CI `[−0.017819, −0.007511]`。

calibration 上 q2 的 regret 改善同样不显著，而且 Brier 与升级空间恶化方向一致。

## 4. 决策 D4-005

2-bit G1 未形成稳定 regret/bit Pareto 改善，并显著损伤校准误差与后续升级可辨识性，因此淘汰。保留 1-bit G1，不训练 q2 价值网络。该负结果说明“增加预览位数”不等于“提升任务调度信息”：当前均值融合下，较细但仍有偏差的节点概率会改变资源排序并提高 Brier，同时减少单节点升级的可纠错空间。

下一批实现 q1 上的可解释解析评分与离散预算调度。评分只使用当前任务块最优—次优间隔、候选节点对当前融合的任务相关分歧、可用质量/链路可靠性和真实期望 bit；先建立贪心及 0-1 背包接口，再与 SNR、confidence、阶段 3 先验和学习网络进行同预算比较。
