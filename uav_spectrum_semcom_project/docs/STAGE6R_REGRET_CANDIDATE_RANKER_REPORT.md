## 1. 研究问题

S6R.3a已经能够判断新活动属于已知上下文还是OOD，并在OOD时根据校准景解析构造小码本。本实验进一步检验：

> 轻量机器学习模型能否根据校准频谱和候选动作特征，预测候选动作在未来窗口内满足regret阈值的概率，从而比解析校准码本取得更高覆盖或更低escape。

模型只负责候选排序。所有紧凑码字仍需满足：

`max[q] R(x,q,a_q) ≤ 0.2 dB`

否则系统escape到精确动作。

## 2. 模型与数据

### 2.1 输入特征

每个“上下文—候选动作”样本包含：

- 8维归一化频谱形状；
- 3维归一化动作坐标；
- 动作相对校准期平均最优坐标的3维偏差；
- 校准期ε覆盖率；
- 平均regret；
- regret标准差；
- 最大regret；
- regret的0.9分位数。

特征总维数为19。任何留出活动未来值都不进入特征。

### 2.2 学习标签

标签为候选动作在训练活动未来32景内满足`R ≤ 0.2 dB`的比例，范围为0—1。

### 2.3 模型

- Ridge线性回归；
- HistGradientBoostingRegressor；
- 单隐层32单元MLP。

所有超参数在脚本化执行前写入配置。模型只在时间门控判定OOD时替代解析校准码本；已知活动继续复用原预装码本。

### 2.4 数据拆分

- 外层：完整活动级留一；
- 训练：其余三个活动产生多个时间校准—未来窗口；
- 测试：留出活动经时间门控停止后的未来后缀；
- 当前数据均为已经消费的开发数据；
- 没有访问新Final数据。

|---:|---:|---:|---:|---:|
| 8 | 97.46% | 95.16% | 0.00点 | 6.39点 |
| 16 | 85.93% | 51.94% | −10.62点 | 15.21点 |
| 32 | 96.14% | 94.44% | 0.00点 | 3.74点 |
| 64 | 96.17% | 94.44% | 0.00点 | 3.11点 |

Ridge通常只能重复解析码本的主要动作，却强制补足4个动作，增加了安装bit和码字符号宽度；N = 16还发生明显跨域失效。

MLP训练误差较低，但留出活动性能明显下降，表明它学习了训练活动的动作—未来关系，未获得可靠的跨活动规律。

## 4. 复杂度

| 模型 | 最大序列化大小 | N = 64全动作预测时间 |
|---|---:|---:|
| Ridge | 1.4 KB | 约5.5 ms |
| 梯度提升树 | 193 KB | 约60.6 ms |
| MLP-32 | 27.5 KB以内 | 约11.8 ms |

模型参数都足够轻量，但N = 64时需要评价27,489个合法动作，梯度提升树的候选枚举推理已经达到约60 ms。因此，机载复杂度不仅取决于模型大小，也取决于候选动作空间。

预测时间受CPU和系统负载影响，只作为本机开发参考，不作为确认性工程指标。

## 5. 为什么训练误差低但外部结果差

梯度提升树训练MAE约0.007—0.010，MLP约0.013—0.018，但OOD活动性能仍然较差，原因包括：

1. 只有4个空中活动，外层留一后模型最多看到3种活动上下文；
2. 2023与2024—2025活动的优选频谱位置近似分居频带两端；
3. 训练标签在同活动时间窗口内重复，样本行数很多但独立活动数量没有增加；
4. 候选排序器被要求外推到训练中未出现的动作—上下文组合；
5. 强制补足K = 4会增加安装开销，而解析方法允许只安装实际必要的动作。

因此，“候选—窗口样本很多”不能替代“独立活动数量足够”。

## 6. 保留门槛判断

预设门槛要求至少一种方法在三个N上同时满足：

- 宏平均覆盖提高至少0.5个百分点；
- 最差活动覆盖不低于94%；
- 载荷节省下降不超过2个百分点；
- 模型小于5 MB；
- 错误码本动作数为0。

结果：

- Ridge：0个N通过；
- 梯度提升树：0个N通过；
- MLP-32：0个N通过；
- 错误码本动作数：全部为0；
- 最终决定：三种学习排序器均不接入主系统。

11类谬误扫描覆盖11/11：

| 类型 | 结论 |
|---|---|

| 幸存者偏差 | 所有模型、N和负结果均保留 |
