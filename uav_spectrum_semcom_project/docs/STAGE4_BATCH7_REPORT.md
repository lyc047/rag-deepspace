# 阶段 4 Batch 7：付费稀疏残差调度草图

日期：2026-07-16  
状态：已完成；可辨识性恢复，但系统级 bit-regret 门槛未通过，C2 停止扩展  
证据范围：受控同场景 C2/H2 开发评价；不支持 final H2 或真实 H3 声明

## 1. 动机与 codec

Batch 6 证明普通 1-bit G1 在所有 scene 上四节点完全相同，而软 occupancy 残差仍明显存在。全量 2-bit G1 会污染融合并恶化 Brier，因此本批保持 1-bit 硬占用作为当前融合输入，只额外编码供调度使用的稀疏残差：

- 每节点选择绝对值最大的 top-2 `soft-hard` 残差；
- 通道索引使用 3 bit，残差幅度使用 3 bit，符号由硬占用 0/1 推断；
- 紧凑传输 sensing SNR、prediction confidence、clipping 和 age；链路成功概率作为接收端 CSI；
- 草图不得替换当前融合 occupancy，只能作为候选价值特征。

独立 bitstream 包含 magic、版本、node、scene tag、通道数、草图配置、1-bit occupancy、紧凑质量和残差条目，共 `113 application bit/node`。编解码、稀疏重构、尾随 bit 拒绝及阶段2链路成本均有单元测试。

## 2. 全节点草图

全四节点发送草图时：

- 全节点预览期望成本从普通 G1 的 `1634.46` 增至 `2012.81 bit/decision`；
- train 中所有节点草图完全相同的 scene 从 100% 降至 0；
- 97.28% 节点对具有非零差异，平均绝对差 0.05849；
- 解析 raw score 唯一值由 1 墠至 1257，非零比例 82.75%，但与反事实 value 的 train 秩相关仅 0.095。

解析方法在 520-bit 增量预算下相对“同样已支付草图”的阶段3先验，validation regret 从 `0.025368` 降到 `0.024717`，总 bit 从 `2530.84` 降到 `2403.06`；calibration 方向一致。该结果说明 PAV 负值区间触发 G0 可以避免部分有害升级。

然而五预注册种子的同结构价值网络仍失败：集成 validation regret `0.025594`、总 bit `2644.78`，且 calibration regret `0.029153`，劣于阶段3先验。网络分支据此永久停止，不选择表现较好的单一 seed。

## 3. 选择性草图

为减少固定成本，按事先冻结的接收端静态 SNR/链路先验，仅节点 2、3 发送草图，节点 0、1 发送普通 G1；其他所有组件不变。

- 固定预览成本降至 `1775.34 bit/decision`；
- train raw score 唯一值 699，秩相关 0.1589；
- 600-bit 预算下解析贪心 validation regret `0.024436`、总 bit `2294.81`、CVaR `0.131286`、clean `0.5600`；
- 同一选择性预览下 SNR-G3 为 `0.024979 / 2363.38 bit`，解析法形成均值 Pareto 改善；
- 但相对真正系统控制——普通 G1 的 SNR-G3 `0.024979 / 2222.50 bit`——解析法多用约 72 bit，只改善约 0.00054 regret，且统计证据不足；
- calibration 上 600-bit 解析贪心 regret `0.025419`，劣于阶段3先验 `0.023929`，方向不一致。

因此不能只在“所有方法已支付新草图”的局部对照中宣称通信效率提升；必须把草图固定开销纳入整个系统比较。

## 4. 数据与侧信息审计

旧价值网络曾将部分本地质量字段作为可用特征，而普通 G1 codec 不携带这些字段。草图实验改为只使用实际紧凑传输字段与接收端 CSI，并完整计费。该修正进一步说明旧网络结果最多是侧信息可用时的诊断，不是最终部署证据。

## 5. 决策 D4-007

草图恢复了候选可辨识性，解析 value/bit 加 G0 在局部公平对照中有效，但固定预览开销和跨 split 稳定性未达到系统级成功门槛。停止继续搜索 top-k、草图节点数、质量位宽、网络或阈值，避免在同一 validation 上迭代过拟合。

C2 保留为完整且可复现的研究链：反事实 marginal regret 标签、真实数字包成本、可部署性审计、G0 贪心、精确多选择背包、稀疏草图 codec 及负结果。论文中不得把它写成已验证的性能贡献；可作为“条件信息价值受预览可观测性与固定开销共同限制”的实验发现。

下一批按总计划进入 C3：在冻结普通 G1/C1 和简单调度基线下，构造 1 对 3、高置信错误、削顶、频移、陈旧与关键节点掉线场景，先验证可靠少数保护或冲突触发补传是否能显著降低 CVaR 且控制误报。
