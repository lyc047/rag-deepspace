## 1. 研究问题

S6.4a证明因果历史特征能够排序下一场景的语义动作失效风险，S6.4b证明预测排序在单独的更新保护闭环中存在小幅收益。S6.4c进一步检验：当码本安装、任务包、ACK、延迟重复包和接收端静默重置同时存在时，预测器是否仍能改善完整恢复状态机。

预测器不选择频谱动作，不改变0.2 dB硬风险约束，也不能抑制自然触发的码本更新。它只承担两个辅助任务：

1. 在高风险自然更新发生前预约一次重复发送机会；
2. 尝试按预测状态调整静默心跳间隔。

错误预约同样记入容量账本，避免把误报当作免费操作。接收端仍采用码本身份校验、信念集合和fail-closed解码。

## 2. 冻结实验设计

- 频谱规模：N = 8、16、32、64；
- 每个N包含60条配对随机轨迹，每条轨迹使用相同故障随机数比较不同方法；
- 故障概率：安装包10%、任务包10%、ACK 20%、延迟重复包10%、上下文重置2%；
- 固定心跳基线：静默20个场景；
- 预约上限：评估场景数的10%；
- 学习阈值：只由训练组折外预测分数的最高10%分位确定；
- 统计方法：5000次轨迹级配对bootstrap，报告95%置信区间；
- 比较方法：无重复、周期重复、上一跳违规启发式、学习型重复、学习型重复加自适应心跳。

## 4. 负结果与边界

1. 最大clean rate增益仅0.319个百分点，明显低于论文主验收中3至5个百分点的期望量级；该模块不能单独作为论文核心创新。
2. N = 64的95%区间跨越0，尚不能确认该规模存在稳定增益。
3. N = 64的可用率由86.856%降至86.677%，尽管clean rate略升，说明可靠性指标之间并非单调一致。
4. 自适应心跳只在2/4种N上满足“降低bit且clean rate损失不超过0.5个百分点”，未达到3/4门槛，因此不保留。
5. CVaR₀.₉没有改善。10 dB中断惩罚仍占据最坏10%尾部，重复保护不足以改变饱和尾风险。
6. 结果来自固定站点开发频谱与合成链路故障，不能外推为真实无人机移动链路可靠性或跨活动泛化证据。

## 5. 统计解释与谬误扫描

总体结论标记为 **CAUTION**，不是强确认。原因是效应小、N = 64不确定、故障为合成注入，且同一协议内存在多个预设规模与方法比较。

1. 辛普森悖论：四种N的学习型重复点估计同向为正，未见方向反转；仍以分N结果为主，不用汇总值替代分层结果。
2. 生态谬误：分析单位是开发频谱轨迹，不对单架无人机或单个真实节点作个体结论。
3. Berkson偏差：存在风险。开发数据来自特定固定站点且已筛选为排除于Final的pilot，不能代表全部部署环境。
4. 碰撞变量偏差：未发现。模型不使用故障注入后的结果变量作控制，也未对处理后的变量进行条件化。
5. 基准率忽视：未发现。报告绝对clean rate、availability和尾部风险，而非只报告相对提升。
6. 均值回归：未发现。轨迹与N不是根据极端结果选择，阈值只在训练组冻结。
7. 幸存者偏差：未发现。全部60条轨迹均进入汇总，没有删除失败轨迹。
8. 多重比较/遍历效应：存在注意项。N与方法在协议中预先声明，保留门槛也预注册，但未对每个单元的区间做多重性校正，因此不能把每个区间单独宣称为确认性显著发现。
9. 分析路径分叉：较低。协议、前序结果哈希、阈值来源和失败动作均在结果访问前冻结；但本实验仍属于开发阶段。
10. 相关代替因果：只允许在受控模拟器内解释“启用策略造成的配对差异”；不能据此宣称真实无线环境中的因果收益。
11. 反向因果：未发现于特征时序。预测只使用当前决策前的因果历史；外部环境中的因果可迁移性仍未验证。

## 7. 阶段决策

- **保留**：学习型风险排序驱动的紧凑更新重复保护，定位为辅助可靠性模块；
- **不保留**：当前高风险状态延长至40场景的自适应心跳规则；
- **不修改**：硬regret触发、码本身份校验、上下文丢失假设和fail-closed解码；
- **下一步**：进入S6.5a“下一码字分类可行性实验”。用长度1、2、4、8的因果历史窗口预测下一任务等价码字，先与持久性、频率先验和马尔可夫基线比较，再决定是否值得引入机器学习频谱预测。
