## 6. 统计解释

### 6.1 有效证据

- 四种 N 的节省率区间下界均明显大于0，说明通信开销优势不是仅由点估计产生；
- N = 16、32 的 clean 下界分别为91.10%和91.18%，对原失败规模形成独立正证据；
- 零错误码本动作说明安全校验和fail-closed边界在本次六站点运行中保持成立。

### 6.2 不确定性

- 只有6个独立站点，站点层自举区间较宽；
- clean区间跨越90%并不等于算法无效，而是当前证据不足以满足预注册的强确认门槛；
- 不能通过增加同一站点的蒙特卡洛轨迹来替代新增独立站点；轨迹只能降低链路随机误差，不能消除站点间异质性；
- 本次测试不可重跑，因此复现状态为 `CANNOT_VERIFY`；代码、种子和环境已冻结，但治理规则优先于重复执行。
