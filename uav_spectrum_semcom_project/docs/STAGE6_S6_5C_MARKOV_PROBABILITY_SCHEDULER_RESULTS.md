## 1. 研究问题

S6.5b发现一阶马尔可夫的下一码字分类准确率高于学习分类器。S6.5c进一步检验：这种分类优势能否转化为通信系统中的实际资源收益。

马尔可夫模型不输出可直接执行的信道动作，只输出下一场景发生任务码字变化的概率。概率较高时，系统提前预约一次紧凑更新重复容量；真实频谱动作仍在下一场景完成感知后，由0.2 dB硬regret约束决定。

## 2. 算法设计

比较三个递进版本：

1. 一阶马尔可夫：仅使用当前任务码字估计下一码字变化概率；
2. 持续时间马尔可夫：进一步考虑当前码字已连续保持1、2～3、4～7或至少8个场景；
3. 持续时间—熵马尔可夫：在变化概率上加入转移分布不确定度，优先保护高变化风险且高不确定的场景。

持续时间模型采用向一阶转移概率收缩的平滑估计，避免稀疏持续时间单元产生零概率。三种方法均使用训练簇最高10%分位作为在线预约阈值，错误预约同样消耗容量。

## 3. 闭环实验

实验完全复用S6.4c的60条配对故障轨迹和混合故障条件：

- 码本安装丢失10%；
- 任务包丢失10%；
- ACK丢失20%；
- 延迟重复包10%；
- 接收端上下文重置2%；
- 固定20场景心跳；
- 最大预约量为评估场景数的10%；
- 采用5000次轨迹级配对bootstrap。

S6.4c中的无重复、周期重复、上一跳启发式和学习风险排序结果均被逐项精确复现。

持续时间—熵版本在N = 8、16、32上的区间明确为正，并在3/4种N上的单位预约容量收益高于周期调度；但只在N = 16上达到或超过冻结学习风险排序的效率，未达到3/4门槛。因此马尔可夫调度器不替代现有学习风险调度器。

持续时间—熵版本在3/4种N上优于简单一阶马尔可夫，所以“状态持续时间和转移熵”作为候选特征保留，但当前控制规则不保留。

## 5. 为什么分类准确率高却没有成为最优调度器

预测下一码字和保护真正发生的紧凑更新不是同一个目标：

- 码字发生变化不一定触发新的紧凑更新；
- 更新还受regret、状态年龄、ACK信念和上下文恢复状态影响；
- 分类正确率不会区分“这次变化是否值得消耗重复容量”；
- 系统收益取决于预约是否恰好落在会失败且重要的更新上。

持续时间—熵模型的评估AUC约为0.698～0.702，AP为0.520～0.550。N = 8时高于学习风险排序，但其余规模没有形成稳定优势。

离散马尔可夫分数还产生大量并列候选：四种N分别出现29、31、47和47个预约候选，而硬预算最多允许17次。现有在线实现按时间顺序使用预算，可能过早耗尽容量。该现象是下一步需要单独验证的机制问题，不能在本轮事后修改。

## 6. 决策

- 马尔可夫硬调度器：不保留；
- 马尔可夫替代学习风险排序：不成立；
- 一阶马尔可夫：继续作为预测准确率强基线；
- 持续时间与转移熵：作为调度特征保留；
- 现有学习风险重复保护：继续保持辅助模块地位；
- CVaR₀.₉仍无改善，所有方法的10 dB中断尾部保持饱和。

## 7. 统计解释与11项谬误扫描

总体置信等级为 **CAUTION**，覆盖11/11项。

1. 辛普森悖论：N = 8、16、32为明确正增益，N = 64区间跨0；不以总体平均掩盖N = 64。
2. 生态谬误：结论单位是开发轨迹，不推断单架无人机。
3. Berkson偏差：存在注意项；固定站点pilot属于选择性开发数据。
4. 碰撞变量偏差：未发现；没有根据预约成功或更新结果筛选样本。
5. 基准率忽视：报告了变化率、AUC、AP、候选数、实际预约容量和clean rate。
6. 均值回归：未发现；N和轨迹没有按极端结果选择。
7. 幸存者偏差：未发现；60条配对轨迹全部进入汇总。
8. 遍历效应：存在注意项；比较三个马尔可夫版本和四种N，但方法、门槛和失败动作均预注册，未对单个单元作确认性显著宣称。
9. 分析路径分叉：较低；持续时间分箱、平滑强度和熵权重均在运行前冻结，但所有pilot簇已参与前期开发，因此仍是探索性证据。
10. 相关代替因果：受控模拟器内的策略差异可作配对干预解释，不能外推为真实无人机链路因果收益。
11. 反向因果：调度分数仅使用当前码字和过去持续时间，未使用下一场景信息。

## 8. 下一步

进入S6.5d“在线预算整形”：

1. 使用训练簇校准每种离散分数的实际候选发生率；
2. 引入因果token bucket，使10%预算随时间逐步释放，避免开头耗尽；
3. 并列候选按持续时间—熵风险和距离上次预约的时间排序；
4. 不使用评估序列的全局排序或未来候选数量；
5. 与当前马尔可夫、学习风险排序和周期调度比较；
6. 只有在至少3种N上同时超过当前马尔可夫和学习风险排序，才保留预算整形调度器，否则终止马尔可夫控制器研究。
