# 阶段8.1：F盘候选数据元数据审计

## 1. 审计目的

本审计只回答一个问题：

> 当前F盘是否已经存在不少于20个、从未用于本项目的新独立频谱单元，可以承担阶段8外部Final？

审计只读取路径、文件名、文件大小以及项目内已经冻结的使用记录，没有打开压缩包负载，也没有读取IQ、功率、占用、regret或算法输出值。

## 2. 审计结论

当前本地满足阶段8新外部Final要求的独立单元数为：

`0 / 20`

因此：

- F盘已连接且剩余空间约172 GB；
- 数据文件本身存在；
- 但现有频谱数据均已见、已消费、被指定为pilot，或与冻结任务不兼容；
- 阶段8 Final当前不可执行；
- 需要寻找或采集新的外部频谱会话。

这一结论不等于“现有数据没用了”。它们仍可用于复现、消融、软件回归、适配器测试、教学展示和未来不同任务研究，只是不能再次承担独立确认性证据。

## 3. 已见且任务兼容的数据

### AERPAW Helikite 2023—2025

- Packapalooza 2023已永久指定为pilot；
- Lake Wheeler 2024和Packapalooza 2024已进入阶段5—6外部流程；
- Packapalooza 2025已经在阶段6被访问，后续元数据修复验证属于开发证据；
- 把同一压缩包切成更多片段不会产生新的独立活动。

### AERPAW Sub-6 GHz 2022

LW1、CC1和CC2已经用于阶段4—6的开发、确认和Final相关实验。剩余未抽取文件仍属于相同活动来源，不能仅因“具体样本尚未逐条运行”就视为全新外部数据。

### ElectroSense spectrum_bands

本地34个站点均已在阶段6被消费或在阶段7转为开发证据。不同N和不同故障随机种子不是新的独立站点。

## 4. 本地其他数据为什么不能替代

| 数据源 | 主要结构 | 不能承担本次Final的原因 |
|---|---|---|
| RML2016.10A | 调制类别IQ片段 | 不含面向连续多信道块选择的有序宽带会话 |
| LoRaIQ | LoRa波形样本 | 任务是波形/设备相关识别，不是频谱块regret |
| 5G短SigMF | 单个短IQ捕获 | 独立单元数量远低于20 |
| FIESTA本地包 | 单个频谱压缩包 | 当前元数据不足以证明20个独立有序会话 |
| RadDet | 雷达目标检测 | 任务域不同 |
| VisDrone | 无人机图像检测 | 可服务未来图像语义研究，但不能验证频谱协议 |

其中RML、LoRaIQ、RadDet和VisDrone并非质量差，而是研究问题不同。把不匹配数据强行转换为占用序列会改变Final任务定义。

## 5. 对后续工作的约束

接下来可以继续做：

1. 在网络上只查公开元数据和论文说明，筛选新的宽带频谱监测数据；
2. 优先寻找具有站点、日期或活动层级的连续功率谱/PSD/SigMF数据；
3. 只有元数据满足不少于20个独立单元、至少3个来源层后，才下载或登记信号路径；
4. 下载后先做只读格式兼容检查，再冻结清单；
5. 最后单次执行外部Final。

不能做：

- 从旧压缩包中切出20段并称为20个独立单元；
- 把不同N、不同信道块或不同故障种子当作独立样本；
- 用合成数据替代外部Final；
- 在看到新信号后调整码本、心跳、阈值或适配规则；
- 用不兼容的调制分类数据证明频谱块选择算法有效。
