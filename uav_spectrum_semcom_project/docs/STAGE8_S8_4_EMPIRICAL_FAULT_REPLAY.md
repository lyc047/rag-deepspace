# 阶段8 S8.4：经验故障模型下的心跳协议重放

## 1. 实验问题

本实验检验：在AADM开发飞行标定出的“会话级链路质量异质性”下，是否存在比固定10景心跳更优的固定间隔。

实验仅改变心跳间隔，以下内容全部冻结：

- 任务查询和0.2 dB容差；
- 多查询任务码本；
- regret与状态年龄触发；
- 累计ACK和接收端信念；
- 精确动作escape；
- 码本激活、完整安装和fail-closed；
- 安装丢失10%、ACK丢失20%、上下文重置2%的压力参数。

使用 N = 8、16、32、64 四种信道规模，每种规模包含4个AERPAW开发活动和4个ElectroSense pilot站点；每个会话运行60条配对轨迹。相同轨迹上的所有心跳方案共享频谱状态、抽取的AADM飞行丢失率和随机数。

## 2. 冻结门槛

相对固定10景基线，候选在至少3种N上必须同时满足：

1. clean差值95%区间下界不低于 −0.5个百分点；
2. 总bit相对节省95%区间下界严格大于0；
3. 错误码本动作执行次数为0。

## 3. 开发结果

下表给出四种N上的均值范围，所有置信区间均采用会话—轨迹层次自助法。

| 心跳间隔 | 相对clean变化 | 相对总bit变化 | 门槛结果 |
|---|---:|---:|---|
| 无固定心跳 | −20.6至−34.2个百分点 | 节省38.1%至49.4% | clean失败 |
| 30景 | −9.1至−9.8个百分点 | 节省28.6%至30.6% | clean失败 |
| 20景 | −4.8至−5.3个百分点 | 节省18.9%至21.9% | clean失败 |
| 16景 | −3.1至−3.5个百分点 | 节省13.8%至15.3% | clean失败 |
| 6景 | +2.25至+2.41个百分点 | 多耗24.5%至26.5% | bit失败 |

所有候选、所有信道规模的错误码本动作执行次数均为0，说明fail-closed和码本身份安全边界保持有效。

## 4. 结论

没有候选通过开发门槛，因此：

- 不生成新的阶段8心跳候选；
- 不使用AADM确认飞行对失败候选继续筛选；
- 固定10景继续保留为当前压力模型下的工程折中边界；
- 该结论不能写成“真实无人机上的最优心跳”，因为ACK和语义上下文重置仍未真实标定。

实验揭示的rate–risk关系具有一致性：放宽心跳间隔确实节省控制bit，但clean损失远超0.5个百分点；缩短到6景确实提高clean，但代价是约四分之一的额外bit。因此，问题不是某个固定常数选错，而是任何固定间隔都只能沿同一条开销—可靠性曲线移动。

## 5. 对后续研究的约束

阶段8不应继续微调固定间隔。若未来获得真实板载上下文状态，可研究基于可观测进程存活、持久化版本和启动计数器的事件式恢复；在此之前，所谓自适应心跳仍可能只是在拟合人为重置概率。

确认阶段只用于验证以下事实是否跨飞行成立：

- 真实任务链路代理是否存在显著会话间异质性；
- 固定10%同质丢包是否仍不充分；
- ALFA是否仍不能标定语义接收端上下文重置。

由于开发侧没有候选，确认阶段不承担候选选择功能。
