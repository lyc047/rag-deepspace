# 阶段7主计划：多步任务与上下文失效风险预测及自适应恢复

版本：1.0
日期：2026-07-30
状态：正式生效；当前入口为 S7.0
上游基线：S6R-FH10-v1
研究类型：解析安全层约束下的轻量人工智能与通信协议联合优化

## Material Passport

- Origin Skill：academic-research-suite / experiment planning
- Primary Evidence Gap：固定10景心跳不能在异质站点和全部 N 上统一满足 clean 置信下界
- Primary Research Question：风险预测能否在相同可靠性下降低总 bit，或在相同总 bit 下提高 clean
- AI Boundary：只预测风险和调度保护，不直接执行频谱动作
- External Final Status：尚未选取；任何新 Final 必须来自未参与开发的新站点或新活动

---

## 1. 研究定位

阶段7只解决一个主问题：

> 在频谱动态、控制包丢失、ACK不确定和接收端静默重置共同存在时，能否用校准的多步风险预测替代“一刀切”的固定周期保护，并改善系统级 rate–risk 前沿。

阶段7不以原始功率预测精度、分类准确率或模型复杂度作为最终成功标准。模型是否保留，只由完整闭环中的 clean、availability、regret、尾部风险和总 bit 决定。

---

## 2. 核心假设

### H1：可预测性

只使用场景 t 及其过去的信息，可以预测当前接收端动作在未来 h 景内超过任务阈值的概率。

### H2：上下文风险可区分

频谱动作失效和接收端上下文失效具有不同诱因。将二者分开建模，再形成联合风险，优于只看当前功率变化或固定静默时间。

### H3：闭环收益

在硬安全规则不变时，风险预测器能够把有限探测、恢复、重复和心跳 bit 优先用于高风险场景，使系统相对于固定10景心跳进入更优 Pareto 前沿。

### H4：轻量模型足够

若任务边界、状态年龄、ACK信念和短期频谱变化已包含主要风险信息，逻辑回归、离散生存模型或梯度提升树应能达到可部署的主要收益；深度时序模型只在明确存在剩余收益时启用。

---

## 3. 预测对象与标签

预测时间范围固定为：

`h ∈ {1, 3, 5, 10} 景`

### 3.1 任务动作风险

`y_task(t,h) = 1`

当且仅当从 t + 1 到 t + h 的任一场景中，当前接收端动作的最大任务 regret 超过 `ε = 0.2 dB`。

### 3.2 上下文失效风险

`y_context(t,h) = 1`

当且仅当在未来 h 景内出现接收端上下文丢失、状态过期、码本身份不一致，或发送端信念无法保证安全解码。

### 3.3 联合 clean 失效风险

`y_any(t,h) = 1`

当 `y_task(t,h) = 1` 或 `y_context(t,h) = 1` 时成立。该标签是闭环保护策略的主要输入。

### 3.4 动作安全剩余时间

`T_fail = 首次发生任务或上下文失效的未来景数`

若观察窗口内未失效，则作为右删失样本进入离散时间生存分析，不能简单标成永久安全。

---

## 4. 因果特征边界

所有特征必须在决策时刻可由发送端获得，并按时间因果顺序构造。

### 4.1 任务与频谱特征

- 当前多查询 regret；
- 各需求下最优块与次优块的代价间隔；
- 当前动作已持续时间和近期切换频率；
- 当前频谱均值、方差、动态范围及相邻信道变化；
- 过去1、3、5、10景的功率变化和任务边界变化；
- N、需求比例 D/N、BANK命中、escape与精确回退状态。

### 4.2 协议与上下文特征

- 距离上次任务更新、ACK、探测、激活和恢复的时间；
- ACK信念集合大小、熵和最近变化；
- 接收端状态年龄的可观测上界；
- session、catalog、codec版本的一致性；
- 最近可观测的包发送结果与ACK结果；
- 最近恢复次数、静默时长和连续失败长度。

### 4.3 严禁泄漏

不得使用未来功率、未来丢包、未来重置、真实接收端隐藏状态或运行结束后才能知道的变量。跨站点、跨活动和跨时间簇时，历史状态必须重置。

## 6. 模型路线

### 6.1 强基线

按以下顺序建立，不可跳过：

1. 固定10景心跳，无预测；
2. 当前 regret 与状态年龄阈值；
3. Persistence风险基线；
4. 一阶 Markov 转移与持续时间基线；
5. L2逻辑回归；
6. 离散时间生存模型；
7. 梯度提升树。

此前 Markov 模型在下一码字预测中强于轻量分类器，但不能直接执行动作。阶段7保留其为可解释风险基线，而不是动作控制器。

### 6.2 条件启用的时序模型

只有当经典模型通过可预测性门槛但闭环收益明显受限，并且站点级有效样本量足够时，才比较：

- GRU；
- TCN；
- 小型状态空间模型。

小型 Transformer、自监督预训练或频带图模型不属于默认阶段7主线。只有在跨站点泛化失败且消融证明长时依赖或跨频带关系确实是瓶颈时，才另行注册。

### 6.3 校准与不确定性

风险分数必须在独立验证站点上采用 Platt 或 isotonic 校准，并报告：

- AUC与Average Precision；
- Brier score与Brier skill；
- Expected Calibration Error；
- 高风险事件召回率；
- 固定告警预算下的误报率；
- 分站点和分 N 的稳定性。

模型不确定时只能提高保护等级或触发精确回退，不得因为“预测为低风险”取消硬安全动作。

---

## 7. 解析安全约束下的闭环控制器

### 7.1 不可学习的硬层

以下规则保持解析和强制执行：

- 当前真实 regret 超阈值时立即更新；
- 码本身份、版本或哈希不一致时禁止码字执行；
- 上下文信念无法保证安全时恢复或 fail-closed；
- 无可接受码字时使用 escape + 精确动作；
- 最大状态年龄不得被预测器延长；
- 错误码本动作执行目标始终为0。

### 7.2 风险驱动的可学习调度层

预测器只从有限动作集合中建议保护：

`U = {不额外保护，轻量探测，提前激活/恢复，重复关键更新}`

第一版采用单调三级策略：

| 联合风险 | 允许的策略 |
|---|---|
| 低 | 保持缓存，心跳上限可放宽到16景 |
| 中 | 使用10景基线或发送轻量探测 |
| 高 | 缩短到6景，或立即探测、恢复；必要时重复关键更新 |

此前被拒绝的自适应规则曾把高风险状态延长到40景，与风险方向相反。阶段7明确禁止高风险时延长心跳。

第二版可把保护选择写成：

`保护优先级 = 预计避免的 clean 失效概率 ÷ 新增 bit`

但最终动作仍须经过硬层投影。阶段7不采用强化学习直接选信道。

## 8. 分阶段执行计划

### S7.0：治理冻结与预言机空间检查

任务：

1. 冻结阶段6收尾报告和固定10景强基线；
2. 建立阶段7数据角色清单和站点级拆分器；
3. 实现四个时间范围的任务、上下文和联合标签；
4. 构造使用真实未来信息的离线预言机保护器，仅测理论上限；
5. 比较预言机与固定10景的 clean–bit 前沿；
6. 注册后续模型门槛、随机种子和统计方法。

决策门：若预言机在相同 clean 下都不能节省至少5%总 bit，且在相同 bit 下不能提高至少1个百分点 clean，则停止复杂预测研究，转向无状态或周期自包含协议设计。

### S7.1：强基线与标签审计

任务：

1. 验证标签跨 N、站点、活动的正样本率；
2. 检查右删失、连续故障簇和标签重叠；
3. 实现固定10景、当前 regret、Persistence和Markov基线；
4. 完成时间因果、组间隔离和无泄漏测试；
5. 输出每个基线的预测、校准和闭环结果。

决策门：标签必须在多数 N 中具有可学习变化，且不能由单个泄漏型状态字段完全决定。

### S7.2：经典多步风险模型

任务：

1. 训练逻辑回归、离散生存模型和梯度提升树；
2. 仅在训练站点内选择特征、正则化和树参数；
3. 在独立验证站点校准概率；
4. 做特征组消融和系数/重要性稳定性分析；
5. 确定单模型或小型集成候选。

预测门槛：

- 至少3/4种 N 的 AUC 高于0.70；
- 至少3/4种 N 的 AP 比正样本率高0.10以上；
- Brier skill 相对常数模型为正；
- 校准后 ECE 不高于0.05，或给出预注册的失败处理；
- 在不超过20%告警预算时，高风险事件召回率至少80%，并在至少3/4种 N 成立。

### S7.3：风险感知恢复闭环

任务：

1. 接入单调三级保护策略；
2. 比较固定6、10、16景心跳与风险自适应策略；
3. 使用共同随机数运行60至100条配对故障轨迹；
4. 统计完整前向、ACK、探测、恢复、重复和回退 bit；
5. 分析误报产生的额外 bit 与漏报产生的 clean 损失；
6. 扫描有限风险阈值形成 Pareto 前沿，不以单点追正。

主系统门槛满足以下任一项：

- clean 差异不低于 −0.5个百分点时，总 bit 至少降低5%，且配对95%区间下界大于0；或
- 总 bit 相当时，clean 至少提高1个百分点，且95%区间下界大于0。

上述结论须在至少3/4种 N 成立，剩余 N 不得出现严重退化；四种 N 的错误码本动作执行次数必须全部为0。

### S7.4：条件式时序模型

仅当 S7.2 已通过预测门槛、S7.3 证明存在闭环瓶颈且预言机仍有明显空间时开展。

任务：

1. 比较GRU、TCN或小型状态空间模型；
2. 参数量、训练时间和推理开销与经典模型并列报告；
3. 做历史长度和时间范围消融；
4. 若深度模型没有改善系统主门槛，则回退至经典模型。

### S7.5：稳健性、复杂度与论文证据

任务：

1. 对丢包率、ACK丢失率、重置率和频谱变化速度做压力测试；
2. 做任务风险头、上下文风险头、校准器和保护动作消融；
3. 报告均值、CVaR₀.₉、最长不可用突发和恢复时间；
4. 使用“先站点/活动、再轨迹”的分层bootstrap；
5. 同时报告场景加权与等站点宏平均；
6. 测模型大小、CPU推理时延和峰值内存。

初步工程目标为模型不超过500 KB、单样本CPU推理低于5 ms、峰值附加内存低于50 MB。该目标是桌面代理约束，待目标无人机处理器确定后重新冻结。

### S7.6：候选冻结与新 Final 准备

任务：

1. 只从通过全部开发门槛的方法中选择一个候选；
2. 冻结代码、配置、模型权重、适配器和环境；
3. 获取不少于20个新独立站点或等效活动单元；
4. 先按元数据冻结纳入排除规则；
5. 完成无信号值dry-run、访问计数和哈希校验；
6. 写明数据不足、适配失败和总体失败的保留规则。

### S7.7：单次外部 Final

任务：

1. 单次读取新 Final；
2. 四种 N 联合报告，不挑选通过规模；
3. 比较风险自适应候选、固定10景和精确动作基线；
4. 报告 clean、availability、regret、CVaR、总 bit、分项 bit、错误动作与复杂度；
5. 无论通过、失败或数据不足，均保留访问记录和原始结论。

## 9. 统计与验收规则

1. 分析单位以独立站点或活动为上层，以配对故障轨迹为下层。
2. 使用共同随机数保证协议比较承受相同故障。
3. 置信区间采用站点/活动优先的分层bootstrap。
4. 四种 N 预先注册；不得事后只汇报有利规模。
5. 主要结论同时要求场景加权与等站点宏平均方向一致。
6. clean、availability和bit必须同时报告；不能用单一均值掩盖不可用突发。
7. 所有预测指标属于中间证据，系统级 rate–risk 才是最终证据。

---

## 10. 终止条件

出现以下任一情况时停止对应分支：

- 预言机没有足够闭环收益空间；
- 模型预测优于随机但不能改善系统主门槛；
- 收益仅来自读取未来信息或跨站点泄漏；
- 深度模型只改善RMSE/AUC而不改善 clean–bit 前沿；
- 新策略导致任一错误码本动作被执行；
- 复杂度明显超过轻量基线但系统收益不稳定；
- 需要反复读取外部 Final 才能选择参数。

---

## 11. 预期论文贡献

若阶段7通过，建议形成以下新增贡献：

1. 面向任务动作与接收端上下文的多时间范围联合失效风险建模；
2. 解析安全投影约束下的风险感知保护与恢复调度；
3. 在完整控制开销和跨站点验证下建立预测质量到 rate–risk 收益的证据链。

若阶段7未通过，仍应保留“预测性能不等于系统收益”的负结果，并据预言机分析判断是否转向无状态语义包或周期自包含帧。
