# 阶段 3 鲁棒性与失效边界结论

## 实验定位

本轮验证质量感知多 UAV 频谱融合在节点数变化、陈旧观测、节点失效和异常高置信
报告下是否优于等权平均。旧阶段 3 测试使用的前 800 个 test 源帧不再参与任何
选择；新留出实验固定从 test 源偏移 1200 开始，使用 200 个滑动时序场景、4 个
受控节点和 5 次独立重复。所有融合方法在同一场景内共享完全相同的成功送达报告
和发送 bit 轨迹。

## 方法修正

1. 将固定 `confidence=1.0` 替换为检测掩膜输出的无标签置信度；
2. 仅在验证集将置信度校准为单节点资源选择的 oracle 等价概率；
3. 采用相邻场景共享 3/4 源帧的滑动构造，让过期节点真正读取历史场景；
4. 显式加入最佳节点失效、高 SNR 节点陈旧、高置信错误报告和组合失效；
5. 以质量感知减等权平均的配对 regret 差及其 95% 置信区间作为 H3 判据。

## 主要结果

| 场景 | 等权平均 regret | 质量感知 regret | 配对差（质量-平均） |
|---|---:|---:|---:|
| 四节点基准 | 0.008752 | 0.008772 | +0.000021，区间跨 0 |
| 两节点异质 | 0.008889 | 0.008800 | -0.000088，区间跨 0 |
| 高 SNR 节点陈旧 | 0.010605 | 0.010617 | +0.000012，区间跨 0 |
| 高置信错误节点 | 0.008673 | 0.009084 | +0.000411，显著变差 |

没有任何场景满足“配对 regret 差的 95% 置信区间低于 0”的预注册成功条件。
最佳单节点约 844 bit/decision 即达到 clean rate 0.793、regret 0.008666，而
四节点质量融合约 3376 bit/decision，clean rate 0.790、regret 0.008772。

## 客观结论

当前半合成关联数据不支持 H3。置信度校准改善了概率误差，但没有转化为稳定资源
选择收益；乘积质量权重还会被高置信错误节点利用。该结果说明阶段 3 的关键问题
不是融合网络容量不足，而是节点信息高度相关、置信度跨域泛化不足，以及缺少异常
一致性约束。

后续只在新的验证协议上研究三项改进：价值/bit 节点选择、跨节点一致性异常门控、
保守权重裁剪。论文正式空间协同结论仍需同源 I/Q 回放或同步多接收机数据；在获得
该证据前，本轮结果应作为方法失效边界，而非多 UAV 协同增益证明。
