## 1. 计划目的

本计划用于把已经完成的阶段4—6研究收敛为一条可验证、可冻结、可复现并能够支撑硕士论文的后续主线。后续工作的重点不是继续增加功能数量，而是依次回答：

1. 当前任务等价语义系统在公平可靠性条件下是否真正降低总通信开销；
2. 解析型任务码本能否跨日期、地点和活动泛化；
3. 任务容差ε、信道数量N和需求比例D/N如何共同决定码率—风险关系；
4. 多步任务失效预测能否进一步改善系统级rate–risk前沿；
5. 真实链路与设备约束下，系统能否维持可接受的时延、内存和上下文安全性。

未经本计划的决策门触发，不扩展到图像语义、多模态、MIMO、多无人机协同、动态图神经网络或强化学习直接选信道。

## 3. 统一研究问题与优化目标

### 3.1 统一研究问题

在频谱动态变化、控制链路不可靠且接收端上下文不确定的条件下，如何以最小通信开销维持接收端动作处于任务可接受集合中？

### 3.2 任务可接受集合

对频谱状态x、任务查询q和候选动作a，任务regret定义为：

`R(x,q,a) = c(x,q,a) − min[a′] c(x,q,a′)`

其中c表示候选连续块的平均功率代价，单位为dB。

多查询任务可接受集合定义为：

`Aε(x) = {a：max[q] R(x,q,a_q) ≤ ε}`

只要接收端动作属于Aε(x)，系统就不要求恢复完整功率谱或逐项传输精确最优动作。

### 3.3 系统目标

主优化目标：

`最小化 E[Σₜ Bₜ]`

约束：

- `Pr(aₜʳˣ ∉ Aε(xₜ)) ≤ δ`；
- `Pr(系统不可用) ≤ η`；
- 在已建模故障和身份校验条件下，错误上下文动作应被fail-closed拒绝。

Bₜ必须包括前向任务包、ACK、心跳、码本安装、恢复、重复和重传的总开销。

## 4. 后续论文贡献边界

计划优先形成三个贡献：

1. 基于多查询regret的任务等价离散码本；
2. 面向不可靠控制链路的有状态语义更新与安全上下文恢复；
3. 解析安全层约束下的多步任务失效预测与有限保护分配。

第三项只有在系统级rate–risk收益达到预注册门槛时才写为正式贡献。若预测收益不足，则保留为负结果或辅助消融，不为增加“人工智能”标签而强行进入主架构。

“错误上下文动作执行概率为0”不得作为无条件理论结论。论文只能陈述：

> 在明确的故障模型、codec身份检查和已执行压力测试范围内，未观测到错误码本动作被执行；未建模的软件、硬件和物理链路故障仍属于限制。

### 5.2 数据量判断原则

当前问题不是只有文件体积不足，而是独立活动、日期、地点和设备数量不足。N = 8、16、32、64是同一原始扫频的不同聚合，不能作为四组独立数据；滑动窗口也不能替代独立活动。

CC1、CC2、LW1三包包含长时间连续宽带扫频，是近期扩充训练数据的第一优先级。正式训练前必须先统计：

- 可解析扫频数；
- 时间覆盖范围与中断；
- 各站点、日期和时段数量；
- 公共频率交集；
- 频率分辨率；
- 重复、损坏和异常文件；
- 可形成的连续因果窗口数；
- 各任务动作和失效标签分布。

- AERPAW CC1/CC2/LW1固定节点数据：<https://datadryad.org/dataset/doi%3A10.5061/dryad.hmgqnk9zn>

优先级为AERPAW同类宽带扫频，其次是ElectroSense跨地点PSD数据。一般RadioML调制识别数据不作为本系统主数据。

### 5.4 合成数据原则

合成数据只能根据真实训练集拟合，不能读取或拟合外部Final分布。推荐顺序：

1. 真实连续时间块重采样；
2. 保留时频相关性的block bootstrap；
3. 半马尔可夫占用和干扰持续时间模型；
4. 噪声底漂移、窄带突发、宽带干扰、缺失频点和扫频错位注入；
5. 前向丢包、ACK丢失、延迟ACK和接收端重置注入；
6. 数据规模充分后再考虑深度生成模型。

合成真实性至少检查：

- 功率边缘分布；
- 时间自相关；
- 相邻频率互相关；
- 干扰持续时间；
- 最优块转移矩阵；
- 最优与次优代价间隔；
- regret分布；
- 任务等价集合大小；
- 码本覆盖率和escape率；
- 合成训练—真实测试和真实训练—合成测试。

### S6.7b：开发集matched-reliability公平曲线

目标：在不修改核心码本的前提下，建立语义系统和精确动作基线各自的最优rate–risk前沿。

扫描：

- 心跳间隔；
- 重复保护预算；
- ARQ次数；
- 最大状态年龄；
- ACK保护；
- 恢复策略；
- 前向、反馈、延迟和重置故障强度。

必须输出：

- total bits/scene—clean rate曲线；
- total bits/scene—availability曲线；
- total bits/scene—任务失效概率曲线；
- 前向、ACK、心跳、安装、恢复和重传开销分解；
- 共同可达clean区间；
- matched-clean下的配对bit差和置信区间；
- 长短会话分层结果。

公平原则：

- 相同频谱场景、任务查询和链路随机轨迹；
- 各方法可使用自身最优协议，但必须计入全部开销；
- 不能只比较2-bit码字和精确索引payload；
- 不能挑选单个最有利工作点而隐藏完整曲线。

决策门：

- 若matched-clean下bit节省的95%置信区间下界大于0，则核心系统优势初步成立；
- 点估计达到15%—20%以上时可形成较强论文结论；
- 若没有共同clean区间或语义系统不在更优Pareto前沿，则暂停Final，优先简化头部、上下文维护或恢复机制。

### S7.1：多步任务失效标签与强基线

触发条件：阶段6外部Final完成，或已为后续AI保留新的独立数据角色。

主要标签：

`pₜ,ₕ = Pr(max[q] R(xₜ₊ₕ,D_q,aₜ) > ε)`

预测范围：

`h ∈ {1, 3, 5, 10}`

同时构建动作安全剩余时间：

`Tfail = min{h：max[q] R(xₜ₊ₕ,D_q,aₜ) > ε}`

模型顺序：

1. Persistence；
2. 一阶Markov；
3. 逻辑回归；
4. XGBoost或离散时间生存模型；
5. 数据规模足够时使用GRU或TCN；
6. 只有轻量模型明显不足且独立活动充足时，才比较小型Transformer。

模型拆分必须按整天、整站点或整活动进行，禁止把相邻窗口随机分到训练和测试。

### S7.2：预测保护闭环

预测器只能控制：

- 重复保护等级；
- 提前任务刷新；
- 心跳优先级；
- 主动上下文恢复。

预测器不能：

- 取消当前真实regret硬触发；
- 绕过码本身份检查；
- 直接执行预测频谱动作；
- 禁止必要escape。

保留门槛：

- 相同clean下total bits至少下降约5%，且配对区间支持正收益；或
- 相同total bits下clean提高至少1个百分点；
- Brier score、校准误差和高风险召回率均达到预注册要求；
- 错误码本动作执行次数在故障模型测试中保持为0。

未达到系统收益门槛时，预测器只保留为辅助或负结果。

### S7.3：轻量自监督频谱表示

这是条件性阶段，不默认执行。

触发条件：

- CC1/CC2/LW1和新增活动审计后具有足够独立时序；
- 随机初始化模型存在明确的小样本或跨活动性能瓶颈；
- 轻量预训练有可能改善任务风险而不只是功率RMSE。

允许方法：

- 时间—频率遮挡恢复；
- 下一时隙预测；
- 轻量一致性学习；
- 1D CNN、TCN或小型Transformer编码器。

不得使用“Spectrum Foundation Model”作为当前工作定位。建议表述为“轻量自监督时频表示编码器”。

保留门槛：

- 跨活动任务风险指标优于随机初始化；
- 改善能够转化为matched-clean下的系统bit收益；
- 模型复杂度适合目标边缘处理器。

### S7.4：码本泛化与OOD条件分支

仅在外部Final或后续跨活动实验显示码本泛化不足时触发。

触发信号：

- escape率明显高于开发值；
- 出现较多新动作元组；
- 外部最大regret恶化；
- 不同活动需要完全不同的解析码本。

方法顺序：

1. 多活动鲁棒集合覆盖；
2. 带码本规模约束的解析集合覆盖；
3. 任务聚类码本；
4. 基于任务特征的轻量OOD检测；
5. 最后才考虑regret感知向量量化码本。

所有学习型码本必须执行：

`AI码字建议 → 精确regret校验 → 安全码字或escape`

学习型码本保留条件：

- 外部escape率下降；
- matched-clean下total bits下降；
- 错误码本动作不被执行；
- 推理时延和内存可接受。

### S8：最小工程验证与论文冻结

硕士论文最低工程验证：

- 目标计算设备推理时延、内存和模型大小；
- 可控前向丢包、ACK丢失、延迟ACK和设备重置；
- 短、中、长会话开销；
- 码本失配和上下文错误的fail-closed验证；
- 可复现脚本、配置、数据清单和结果哈希。

真实无人机飞行、多节点、MIMO和多模态不作为当前论文完成条件。若设备和时间允许，可进行硬件在环或小规模静态SDR验证作为加分项。

### 7.1 数据拆分

- 预测模型按活动、日期、站点或时间簇分组；
- 相邻窗口不得跨训练/测试边界；

- 所有方法使用共同随机链路轨迹；
- 对相同场景计算配对差；
- bootstrap以时间簇、日期或活动为抽样单位；
- 同时报告点估计、95%区间和实际效应量；
- 大量参数扫描时报告完整曲线并控制选择偏差。

### 7.3 指标优先级

主要指标：

- matched-clean total bits/scene；
- 任务失效概率；
- availability；
- 外部escape率。

次要指标：

- 平均和最大regret；
- CVaR₀.₉；
- 前向、反馈、心跳和恢复开销；
- 更新率和切换次数。

AI辅助指标：

- AUC与Average Precision；
- Brier score；
- Expected Calibration Error；
- 高风险事件召回率；
- OOD AUROC；
- 推理时延和峰值内存。

AI指标不能替代系统级rate–risk收益。

## 8. 决策树与止损规则

### 情况A：matched-clean优势成立，外部码本稳定

保留解析码本，不开发神经码本；进入多步任务失效预测。

### 情况B：matched-clean优势不成立

暂停Final或后续AI，依次检查：

1. 48-bit头部和身份字段是否抵消payload收益；
2. 心跳、重装和ACK是否过重；
3. 状态协议是否只适合长会话；
4. 是否需要周期性自包含帧或半状态语义；
5. 基线是否处于更优可靠性工作点。

### 情况C：外部escape率或新动作元组显著上升

进入鲁棒解析码本和轻量OOD分支，不先训练复杂VQ。

### 情况D：接收端重置仍是主要瓶颈

优先研究周期性自包含帧、上下文摘要和低成本存活确认，不继续压缩码本。

### 情况E：AI预测准确但系统收益不足

保留为负结果或辅助分析，停止扩大模型；不能仅凭AUC、RMSE或模型复杂度写为创新。

### 情况F：数据独立活动不足

优先增加AERPAW跨年份、跨活动和跨站点真实数据；合成数据只用于增强，不替代外部真实验证。

## 15. 2026-07-29阶段6R活动稳定性与恢复归因更新

> 在长会话占比较高的开发场景加权口径下，clean = 0.90能够获得正收益；短活动和频繁冷启动仍会被上下文安装开销反超。

### 15.2 恢复安装主因

五因素Shapley归因表明：

1. ACK丢失贡献约14.81—17.76 bit/景恢复安装；
2. 接收端重置贡献约5.76—6.58 bit/景；
3. 单次任务包工作点的任务丢失贡献约7—8 bit/景；
4. 安装包丢失贡献不足0.7 bit/景；
5. 延迟重复ACK不增加恢复安装，但增加约2.3 bit/景反馈开销。

因此，继续减小语义码字或提高轻量排序器准确率不是当前主矛盾。
