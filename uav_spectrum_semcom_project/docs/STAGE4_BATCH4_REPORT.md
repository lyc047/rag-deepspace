# 阶段 4 Batch 4：C2 反事实价值标签与因果调度验证

日期：2026-07-16  
状态：已完成；Gate B 的当前轻量价值网络未通过，转入可解释调度与预览可辨识性实验  
证据范围：受控同场景多节点开发数据，仅支持 C2/H2 开发判断，不支持 final H2 或真实 H3 声明

## 1. 本批目标与冻结规则

本批承接 Batch 3 冻结的 `detection+resource` C1 checkpoint，完成：

1. 构造四个受控节点观测，每个节点具有不同 sensing SNR、增益、频移、上报 Eb/N0 和 age；
2. 在 train split 枚举当前融合状态、候选节点与 G2/G3 升级，生成反事实 occupancy-regret 边际价值标签；
3. 使用 Batch 1 的真实语义 codec 和阶段 2 的分包、头部、CRC、FEC、调制填充、截断 ARQ 与时延规则计算节点特定期望 bit；
4. 训练五个预注册种子的轻量价值网络，并与不升级、SNR、置信度、阶段 3 先验 value/bit 和 oracle 比较；
5. validation 只输出聚合评价，不保存逐候选监督标签；final holdout 保持未建立、未访问。

价值网络在训练前冻结为 55 维可部署输入、`64-32` MLP、100 轮、五个种子、Huber 回归加组内 listwise 排序损失。固定使用末轮模型和五种子均值，禁止按 validation 挑 epoch 或最佳 seed。

## 2. 因果与数据访问审计

反事实候选的 G2/G3 高精度报告只参与训练标签和离线结果计算，不进入调度器输入。部署特征仅包括：

- 已收到的当前融合信念与候选节点当前粒度报告；
- 可用的质量字段及 availability mask；
- 当前节点粒度状态、候选节点、目标粒度；
- 节点特定的期望数字链路成本。

代码会拒绝在非 train split 生成反事实监督标签。训练集保存 300 个 scene、2700 个条件状态组、18000 个候选标签，每个 scene 60 个标签；calibration 和 validation 均未保存标签，final holdout 访问次数为 0。

## 3. 标签与 oracle 可学习性

训练标签中正/零/负边际价值比例为 `0.1749 / 0.6768 / 0.1482`，不是全零或单一符号。validation 一步 oracle 在 52.67% 场景找到有效升级，将平均 regret 从 `0.028172` 降至 `0.005500`，说明任务仍存在较大条件信息价值，但不代表该价值可由当前 G1 预览可靠预测。

## 4. 公平通信成本修正

初版评价只计候选升级包，遗漏了调度前已经发送的全节点 G1 预览。该中间结果作废。最终报表将四节点 G1 应用层消息逐一通过同一数字链路，全部方法均计入约 `1634.46 bit/decision` 的期望预览成本；升级包在此基础上累加。G1 按 codec 规定只携带粗占用，不错误附加 G2/G3 的 83-bit 质量块。

## 5. validation 结果

| 方法 | 平均 regret | CVaR0.9 | 期望总发送 bit | clean rate |
|---|---:|---:|---:|---:|
| 不升级 | 0.028172 | 0.145275 | 1634.46 | 0.4800 |
| sensing SNR，G3 | 0.024979 | 0.134724 | 2222.50 | 0.5267 |
| confidence，G3 | 0.028772 | 0.139949 | 2553.54 | 0.4533 |
| 阶段 3 先验 value/bit | 0.025368 | 0.136736 | 2152.49 | 0.5267 |
| 学习反事实 value/bit | 0.025075 | 0.114811 | 2215.33 | 0.4867 |
| 一步 oracle | 0.005500 | 0.050784 | 1970.69 | 0.7400 |

配对 scene bootstrap（10000 次）表明：

- 学习方法相对 SNR-G3 的 regret 差为 `+0.000096`，95% CI `[-0.004837, 0.004432]`，无显著改善；bit 差为 `-7.17`，CI 也跨 0；
- 相对阶段 3 先验，regret 差为 `-0.000294`，95% CI `[-0.005562, 0.004602]`，但多用 `62.84 bit`，bit CI `[43.18, 83.38]`；
- 学习方法的 CVaR 为 `0.114811`，低于简单基线，说明尾部排序可能有价值，但不足以单独通过平均性能与成本联合门槛；
- calibration 上学习方法 regret 为 `0.032244`，劣于阶段 3 先验的 `0.023929`，显示跨开发 split 稳定性不足。

## 6. 异常修复与验证

训练过程中发现并修复两项实现问题：

1. listwise mask 的 `0×(-∞)` 导致日志 NaN；修复后五个种子的回归、排序与总损失均为有限值，并从头重训；
2. 总 bit 遗漏 G1 预览；修复粒度特定 codec 字段后从头重跑评价。

## 7. 决策 D4-004

当前 1-bit/子信道 G1 预览下，轻量价值网络未稳定超过 SNR 或阶段 3 先验，因此不进入动态粒度联合训练，也不继续在同一 validation 上搜索网络结构和损失权重。保留网络、标签和完整负结果作为因果可部署性证据。

下一批只改变一个主要因素：在协议已允许的范围内将 G1 从 1 bit/子信道提高到 2 bit/子信道，检查更细预览能否缩小 oracle—可部署调度器之间的可辨识性差距；所有预览成本重新计入。若仍无稳定提升，则按总计划退回非神经的离散贪心/背包调度，将 C2 创新落在反事实标签、实际链路成本和可解释约束求解，而不强行保留价值网络。
