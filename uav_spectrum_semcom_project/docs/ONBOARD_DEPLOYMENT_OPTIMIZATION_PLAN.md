# 低空无人机多模态语义通信系统优化计划

## 1. 计划目标

当前项目已经完成软件仿真级闭环：频谱观测经过频谱语义提取后参与多无人机资源选择，所得链路状态再与视觉语义、任务优先级和候选载荷共同输入决策层，自适应选择摘要、目标语义、ROI、低分辨率图像或完整 JPEG 的传输方式。

下一阶段不再以单独提高视觉检测精度为唯一目标，而是面向无人机实际部署，将系统升级为：

> 任务重要性感知、频谱状态感知、机载资源感知，并能够在真实计算、能耗、时延和无线链路约束下运行的视觉—频谱双语义闭环。

当前可复现实验基线如下：

| 模块 | 当前基线 |
|---|---|
| 频谱语义 | `semantic_hard_rep3`，4 UAV、packet loss=0.2、BER=1e-4 时 clean rate=0.9308，约 3,137.7 bit/决策步 |
| 视觉语义 | YOLOv8s，640 输入，batch=1，AMP off，conf=0.05，固定 top-k=80 |
| 视觉闭环 | 平均约 5,474.9 bit/帧，utility=1.0305，视觉语义质量=0.7471 |
| 决策模型 | 单步 DQN/contextual-bandit，并保留规则策略和 Oracle 上界 |
| 验证形态 | 真实 VisDrone 图像预测接入软件仿真链路，尚未完成同机实时采集和实物无线闭环 |

## 2. 重要性等级

| 等级 | 含义 | 执行要求 |
|---|---|---|
| **P0：核心必做** | 直接决定课题是否具备明确创新点、可信实验和闭环完整性 | 优先完成，未完成前不宜宣称系统面向实际无人机部署 |
| **P1：重要增强** | 显著提高现实性、论文质量和实物落地能力 | 在 P0 主链路稳定后完成 |
| **P2：扩展研究** | 面向更高水平论文或后续设备升级的拓展项 | 不阻塞第一版论文级系统形成 |

| 顺序 | 优化步骤 | 重要性 | 主要产出 |
|---:|---|---|---|
| 0 | 固化当前闭环基线与统一评价协议 | **P0** | 可重复基线、统一指标表 |
| 1 | 任务重要性感知与动态语义预算 | **P0** | 动态 top-k、重要性语义包、预算控制器 |
| 2 | 机载算力、时延与能耗建模 | **P0** | 资源剖析数据、能耗模型、资源感知效用函数 |

| 5 | 轻量化与机载推理优化 | **P1** | 轻量模型、量化版本、端侧性能对比 |

## 4. 分步任务与验收标准

### 步骤 0：固化当前基线与评价协议

**重要性：P0（核心必做）**

目的：保证后续每项优化都与同一基线、公平链路条件和一致任务目标比较，防止模型、数据和奖励函数同时变化导致结论不可解释。

任务：

1. 固定训练集、验证集、测试集和随机种子；
2. 固定当前 YOLOv8s top-k=80、规则策略、单步 DQN 和 Oracle 配置；
3. 统一输出检测指标、频谱选择指标、语义载荷、端到端效用和失败率；
4. 保存运行命令、模型校验值、依赖版本和原始结果 JSON；
5. 增加重复实验，报告均值、标准差和 95% 置信区间。

验收标准：

- 相同配置重复运行能够得到统计一致的结果；
- 所有方法使用相同测试帧、链路样本和效用函数；
- 后续每个优化结果都能自动生成相对当前基线的差值表。

### 步骤 1：任务重要性感知与动态语义预算

**重要性：P0（最高优先级）**

目的：将固定 `top-k=80` 升级为真正面向任务和链路的语义选择机制。这是区别于普通目标检测和图像压缩的核心研究点。

为每个视觉目标定义重要性：

\[
I_i=w_c(c_i)\,w_r(r_i)\,w_e(e_i)\,w_t(t_i)\,f(p_i,u_i)
\]

其中类别、任务区域、异常事件、时效性、置信度和不确定性共同影响目标价值。

任务：

1. 建立可配置类别权重和任务模式，例如搜救、道路监控、设施巡检；
2. 增加区域、事件、新目标、持续未上报目标和跟踪状态权重；
3. 将语义框排序从单纯置信度改为任务价值或价值/bit 比；
4. 根据 clean rate、packet loss、队列和预算动态选择 top-k；
5. 对高价值目标允许发送 ROI，对普通目标只发送类别、位置和跟踪 ID；
6. 加入最低保障规则，避免低置信度关键目标被全部丢弃。

建议对照：

- 固定 top-k=80；
- 仅按置信度排序；
- 按类别重要性排序；
- 按价值/bit 排序；
- 学习式动态预算策略；
- Oracle 预算上界。

验收标准：

- 在相同平均 bit 预算下，关键目标送达率和任务效用高于固定 top-k；
- 在达到相同关键目标送达率时，平均传输 bit 数更低；
- 链路恶化时语义包能自动收缩，且关键目标的下降速度慢于普通目标；
- 至少覆盖三种任务权重配置，证明策略可以按任务改变行为。

### 步骤 2：机载算力、时延与能耗建模

**重要性：P0（核心必做）**

目的：把“模型能运行”升级为“模型在无人机资源约束下值得运行”。

总能耗至少包含：

\[
E_{total}=E_{sense}+E_{infer}+E_{encode}+E_{tx}+E_{retrans}
\]

任务：

1. 测量视觉模型和频谱模型的参数量、模型大小、峰值内存和推理时延；
2. 分别统计 CPU、GPU 或目标嵌入式设备上的运行数据；
3. 建立发送 bit 数、发射功率、传输时间和重传次数对应的通信能耗模型；
4. 统计端到端时延：感知、推理、打包、排队、传输和解码；
5. 将剩余电量、计算负载和温度/降频状态加入系统状态；
6. 将能耗、时延和队列惩罚加入统一效用函数。

建议效用函数：

\[
R=U_{task}-\lambda_b B_{tx}-\lambda_e E_{total}-\lambda_d D_{e2e}-\lambda_q Q
\]

验收标准：

- 能够输出每帧、每秒和每个成功任务的计算与通信成本；
- 能解释“发送语义、ROI 或图像”在何种条件下更节能；
- 给出至少两个视觉模型和两个运行配置的精度—时延—能耗折中曲线；
- 明确说明当前 PC 测量值、估算值和目标机载平台实测值之间的区别。

### 步骤 3：多步 MDP 与资源感知联合决策

**重要性：P0（核心算法升级）**

目的：将当前单步 DQN/contextual-bandit 扩展为动作会影响未来状态的真正时序决策系统。

状态建议增加：

- 当前和历史频谱 clean rate；
- packet loss、BER 和频谱变化速度；
- 待传语义队列、ROI 队列和语义新鲜度；
- 目标重要性分布与未成功上报次数；
- 剩余电量、计算负载和模型工作模式；
- UAV 速度、任务阶段和预计信道驻留时间。

动作建议包括：

- 视觉检测频率和输入分辨率；
- 频谱感知周期；
- 动态 top-k 或 bit 预算；
- 语义、ROI、低清图、JPEG 传输模式；
- 信道、带宽、发射功率和重传保护等级。

任务：

1. 建立包含队列、缓存、语义过期和电池状态的离散时间环境；
2. 先实现启发式、贪心或动态规划基线；
3. 实现 Double/Dueling DQN，必要时再研究 PPO 等方法；
4. 分离训练场景与测试场景，验证对未知链路压力的泛化；
5. 加入硬约束或安全回退策略，保证关键数据最低可靠性。

验收标准：

- 在相同任务效用下减少能耗、时延或队列溢出；
- 在相同能量预算下提高关键语义送达率；
- 优于随机、固定策略、规则策略和单步 DQN；
- 在未见过的 packet loss、UAV 数量或任务权重下仍保持稳定收益。

### 步骤 4：频谱语义现实性与鲁棒性增强

**重要性：P0（可信度必做）**

目的：证明频谱语义不仅在当前仿真分布下有效，而且能适应真实低空无线环境。

任务：

1. 扩展不同 SNR、占用密度、干扰类型、带宽和信号持续时间；
2. 模拟多 UAV 观测差异、遮挡、隐藏节点和局部错误；
3. 加入频谱快速变化及语义包传输后过期的问题；
4. 评估未知调制、未知干扰和分布外场景；
5. 使用真实或 SDR 采集频谱数据评估仿真到现实的域偏移；
6. 为高不确定频谱语义增加 soft 信息、重复保护或请求原始局部谱图的回退机制。

验收标准：

- 给出检测质量、clean rate、regret、失效概率和语义开销的联合结果；
- 在域偏移和快速变化条件下仍优于随机资源选择；
- 证明语义新鲜度、置信度和保护等级确实会改变资源决策；
- 明确频谱语义失败时的安全回退方式。

### 步骤 5：轻量化与机载推理优化

**重要性：P1（重要增强）**

目的：在不显著损失任务效用的前提下降低机载模型计算量和功耗。

任务：

1. 保留 YOLOv8s 作为较强精度基线，加入 YOLOv8n 或其他轻量模型；
2. 测试降低输入尺寸、降低检测帧率和检测+跟踪组合；
3. 导出 ONNX，条件允许时测试 TensorRT FP16/INT8；
4. 评估结构化剪枝、量化感知训练和知识蒸馏；
5. 让视觉模型和频谱模型错峰运行，避免瞬时算力与功率峰值；
6. 根据电量和任务压力动态切换视觉模型、分辨率和推理频率。

验收标准：

- 同时报告 mAP、关键目标召回、闭环效用、FPS、峰值内存和功耗；
- 获得至少一个满足目标平台实时要求的部署配置；
- 轻量版本的任务效用损失可解释，并由能耗或时延收益补偿；
- 不用单一 mAP 判断机载模型优劣。

### 步骤 6：记录回放与 SDR 半实物闭环

**重要性：P1（重要增强）**

目的：在上无人机前，用可控方式验证真实数据输入、真实处理时延和真实无线接口。

任务：

1. 建立时间戳统一的图像、I/Q/频谱和链路状态记录格式；
2. 先以真实记录数据离线回放整个闭环；
3. 使用 SDR + PC/Jetson 完成硬件在环频谱感知和传输；
4. 测试实时数据缓存、异步处理、丢包、超时和重传；
5. 对比仿真链路模型与实测链路的偏差并校准参数。

验收标准：

- 同一时间轴上完成视觉语义、频谱语义、决策和传输日志记录；
- 系统能够连续运行，无持续队列增长和内存泄漏；
- 报告实测端到端时延、吞吐、丢包、能耗和任务效用；
- 仿真参数经过实测数据校准。

### 步骤 7：实机无人机验证

**重要性：P2（扩展研究）**

目的：验证振动、运动、遮挡、散热、电池和空地链路波动对整个闭环的影响。

任务：

1. 先做地面静态和手持移动测试，再进行受控飞行；
2. 测试起飞、巡航、转弯和返航阶段的计算及通信状态；
3. 记录机载功耗、温度、推理帧率、链路和语义送达情况；
4. 验证失联、电量不足和模型异常时的安全回退策略。

验收标准：

- 完成可重复的短时飞行实验；
- 实测资源占用不影响飞控安全；
- 关键语义在链路波动下仍能优先上报；
- 给出仿真、半实物和实机结果之间的差异分析。

### 步骤 8：论文级消融与统计验证

**重要性：P0（论文结论必做）**

目的：证明性能提升来自提出的联合机制，而不是数据划分、奖励权重或某个单独强模型。

必须包含的消融：

1. 无频谱语义、仅频谱语义、频谱与视觉联合决策；
2. 固定 top-k、置信度 top-k、任务重要性 top-k、学习式动态预算；
3. 无能耗约束、仅 bit 约束、计算+通信联合能耗约束；
4. 规则、随机、单步 DQN、多步策略和 Oracle；
5. 不同 UAV 数量、packet loss、BER、队列压力和电量水平；
6. YOLOv8n、YOLOv8s 和轻量化模型；
7. 仿真数据、真实记录回放和硬件在环结果。

验收标准：

- 主结果至少使用多个随机种子并报告置信区间；
- 同时报告任务效果、通信成本、计算成本、能耗、时延和可靠性；
- Oracle 只作为上界，不能作为可部署方法；
- 结论明确区分仿真证明、真实数据验证和实物部署验证。

## 5. 推荐近期迭代安排

在当前设备和代码基础上，近期最合理的连续迭代是：

1. **先完成步骤 0**：固化 YOLOv8s top-k=80 与频谱闭环基线；
2. **立即实施步骤 1**：加入任务权重配置、重要性排序和动态 bit/top-k 预算；
3. **同步完成步骤 2 的 PC 侧剖析**：先测时延、显存和估算能耗，不等待新设备；
4. **在上述状态和成本模型稳定后实施步骤 3**：建立队列和电池驱动的多步 MDP；
5. **用步骤 4 和步骤 8 做压力测试与消融**，形成第一版论文级结果；
6. 设备条件具备后再进行步骤 5、6 和 7 的部署验证。

## 6. 第一版论文级完成条件

满足以下条件时，可以认为系统从“闭环原型”升级为“论文级资源感知闭环”：

- 视觉和频谱语义均由实际模型输出，不使用 GT 代替部署输入；
- 动态语义预算在相同 bit 或能量约束下优于固定 top-k；
- 效用函数显式包含通信、计算、时延或队列成本；
- 多步策略在至少一种压力条件下稳定优于规则和单步 DQN；
- 完成频谱域偏移、链路扰动和多 UAV 压力测试；
- 所有核心结论具有消融实验、重复实验和统计不确定性；
- 对“仿真可行”“真实数据有效”和“实物可部署”三个结论层级进行严格区分。
