## 1. 本批目标与结论

本批完成阶段4的三个前置条件：冻结数据与实验访问规则；建立可逐bit审计的G0—G3数字语义格式；建立不依赖“SNR越高必然越可靠”的前端质量特征。新增19项测试全部通过，全项目回归为83项通过。

这说明阶段4已具备实现Gate A资源损失和后续节点—粒度调度的稳定接口，但尚未产生算法优越性证据，也未解决正式final holdout与真实多接收机场景不足的问题。

## 3. G0—G3 bit格式

应用层公共头为68 bit，包含magic、版本、粒度、节点ID、scene CRC32标签、子信道数和量化位宽。

设子信道数为$N$，每个占用概率量化位宽为$q$，G3证据数量为$E$：

| 粒度 | 应用层bit数 | 内容 |
|---|---:|---|
| G0 | 0 | 静默，不建立数据包 |
| G1 | $68+Nq$ | 粗占用预览 |
| G2 | $151+Nq$ | 占用概率+83 bit质量元数据 |
| G3 | $159+Nq+40E$ | G2内容+证据数量+局部证据 |

量化推理使用真实离散码字；概率重构最大误差不超过$0.5/(2^q-1)$。G3每条局部证据编码起止子信道、类别、置信度和不确定性。

应用层bit随后进入阶段2统一数字链路；总发送bit由协议头、CRC、对齐、FEC、调制填充和重传共同决定。G0严格为零发送；其他粒度只有在全部分片成功译码后才运行应用解码器。选择性分片恢复若后续需要，必须作为新协议版本单独比较。

## 4. 质量特征定义

本批实现：

- 削顶比例：实部与虚部ADC分量超过声明满量程比例；
- 带外泄漏：声明目标频带外功率占总功率比例；
- 噪声底稳定性：逐时间帧低分位噪声底dB的样本标准差；
- 峰背比：峰值功率相对背景分位功率的dB差；
- 预测熵：各子信道Bernoulli占用概率的平均归一化熵；
- 同时保留SNR、置信度、age、上报成功概率和校准误差。

这些量保持为向量，不在本阶段硬编码成SNR单调总分。测试确认相同18 dB SNR下，正常样本与完全削顶样本能够由削顶特征区分。

## 6. 当前边界

1. 当前codec是协议v1，不支持部分G3证据分片独立恢复；
2. 质量特征已定义和测试，但尚未在独立calibration数据上拟合可靠度；
3. 当前仅证明接口正确与bit可审计，不证明RAVES优于基线；
4. final holdout仍未建立；
5. LoRaIQ两事件仍只用于接口和失效机制pilot，不能证明H3。
