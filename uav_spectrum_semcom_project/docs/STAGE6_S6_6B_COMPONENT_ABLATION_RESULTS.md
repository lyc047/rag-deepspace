## 1. 研究问题

S6.6a已经在结果访问前冻结候选架构。S6.6b回答三个问题：

1. 学习型更新重复保护是否带来可复现但有限的可靠性增益；
2. 固定静默心跳是否确实解决了接收端静默重置的可用性问题；
3. 上下文信念恢复是否是可靠闭环的必要组成，而不只是增加协议复杂度。

同时加入无故障理想反馈上界和逐场景精确查询动作包参考，用于展示当前系统相对理想信息与高冗余自包含传输的距离。

## 2. 实验设计

所有方法使用相同的167个评估场景、60条蒙特卡洛轨迹和配对随机数。信道规模为N = 8、16、32、64，任务需求分别为0.25N、0.50N和0.75N。混合故障固定为：

- 码本安装包丢失率0.10；
- 任务包丢失率0.10；
- ACK丢失率0.20；
- 延迟重复概率0.10；
- 接收端上下文重置概率0.02。

完整候选使用ε = 0.2 dB、最大状态年龄120 min、固定H = 20场景心跳，以及最多占评估场景10%的学习型更新重复保护。六组系统为：

| 组别 | 含义 |
|---|---|
| 完整候选 | 冻结的阶段六候选架构 |
| 移除学习保护 | 保留信念恢复与固定心跳，不重复保护高风险更新 |
| 移除固定心跳 | 保留信念恢复与学习保护，静默期不探测 |
| 移除上下文信念恢复 | 使用发送成功假设；由于心跳恢复依赖信念状态，该组同时移除依赖的恢复动作 |
| 理想反馈上界 | 无安装、任务、ACK或重置故障 |
| 精确查询动作包参考 | 每场景发送三个精确最优块坐标，自包含且不依赖码本安装或ACK |

“移除上下文信念恢复”是预先声明的依赖组消融，不能解释成只改变一个变量的纯因果效应。

完整系统在四种N上的clean rate约为84.1%至86.2%。有效CVaR₀.₉均为10 dB，不是频谱选择误差本身达到10 dB，而是超过10%的场景仍出现不可用状态，导致最差10%样本被预注册的10 dB掉线惩罚主导。

## 4. 模块贡献

表中clean增益定义为“完整候选减去对应消融组”，单位为百分点；区间是60条配对轨迹bootstrap的95%区间。

| N | 学习保护clean增益 | 固定心跳clean增益 | 信念恢复依赖组clean增益 |
|---:|---:|---:|---:|
| 8 | +0.150 [0.080, 0.230] | +24.481 [20.489, 28.334] | +59.940 [53.293, 65.778] |
| 16 | +0.319 [0.170, 0.509] | +8.084 [6.387, 9.940] | +61.876 [56.457, 66.926] |
| 32 | +0.259 [0.180, 0.349] | +8.303 [6.636, 10.060] | +56.647 [50.059, 62.884] |
| 64 | +0.100 [−0.449, 0.459] | +8.124 [6.547, 9.741] | +57.355 [50.698, 63.753] |

### 4.1 学习型更新重复保护

学习保护在4/4种N上得到正clean点估计，在N = 8、16、32的95%区间高于0，达到预注册的3种N支持门槛。增益只有0.100至0.319个百分点，因此它应继续被描述为**辅助可靠性机制**，不能写成阶段六的主要性能来源。

它对应用层实际bit的影响分别为−0.158、+0.662、+0.274和−1.229 bit/场景。正值表示重复包增加了实际开销，负值表示保护成功后减少了后续恢复开销。N = 64的clean区间跨0，而且有效平均regret反而增加0.0166 dB，说明该规模下仍存在尾部风险—平均性能权衡。

### 4.2 固定静默心跳

固定H = 20心跳在4/4种N上获得区间显著为正的clean增益，证明它确实能发现普通ACK信念机制无法凭空识别的静默接收端重置。代价是增加9.043至14.958 bit/场景。它是当前混合重置故障模型中的主要可用性组件，但不是免费收益。

### 4.3 上下文信念恢复依赖组

完整系统相对“发送成功假设”依赖组提高56.647至61.876个clean百分点，同时增加26.461至32.108 bit/场景。结果说明在存在安装丢失、ACK丢失、延迟重复和上下文重置时，低开销但无状态不确定性管理的方案会严重失效。

该效应包含信念恢复及依赖它的心跳恢复动作，不能把约60个百分点全部归因于单一数据结构。

|---:|---:|---:|---:|---:|---:|

完整系统相对逐场景精确动作包节省28.46%至37.62%的应用层bit，超过阶段六“相同风险下节省20%”目标的开销量级，但两者的clean rate并不相同：精确包高出约11.4至14.2个百分点。因此这组结果只能说明二者处于不同的开销—可靠性工作点，不能宣称已经在相同clean rate下完成20%以上节省。

理想反馈上界的clean rate为100%，只需约6.006至9.329 bit/场景。这不是可实现基线，而是揭示当前实际开销主要来自故障检测、上下文恢复和反馈不确定性，而不是码字payload。

## 6. 统计与研究判断

本次消融支持以下结论：

1. **正结果**：学习型保护在3/4种N上获得配对区间支持，作为辅助模块保留是有证据的；
2. **正结果**：固定心跳在4/4种N上显著提高可用性，是当前重置故障条件下的必要恢复组件；
3. **正结果**：信念恢复依赖组在4/4种N上贡献巨大，表明协议状态同步是系统级创新不可缺少的一部分；
4. **负面边界**：完整系统仍有13.8%至15.9%的非clean场景，CVaR₀.₉被掉线惩罚封顶；
5. **负面边界**：学习模块增益远小于信念恢复和心跳，论文不能把机器学习预测写成主要创新或主要收益来源；
6. **未成立结论**：尚未证明在相同clean rate下相对精确包节省20%以上。

消融结果不授权修改冻结架构，也不用于重新调节H、ε、状态年龄或学习阈值。

## 7. 可复现性与谬误扫描

主结果和独立复现文件逐字节一致，SHA-256均为`df5a1ba9e924a2af44dcf9035eda54b157f2d4502c8fdd27c9a585c306a11249`。完整候选与“移除学习保护”两组还分别精确复现了S6.4c冻结前驱中的学习重复保护和无重复基线。所有方法的错误码本动作执行次数为0，Final状态前后完全一致。

11项检查结论：

1. 辛普森悖论：逐N报告，不用合并均值替代异质结果；
2. 生态谬误：固定站点活动不外推为真实无人机移动可靠性；
3. Berkson偏差：开发缓存为排除型样本，结论标记为开发证据；
4. 碰撞变量偏差：不按成功轨迹筛选样本；
5. 基准率忽视：同时报告绝对clean、bit和regret；
6. 均值回归：使用全部冻结评估时间簇；
7. 幸存者偏差：60条轨迹全部纳入；
8. 遍历效应：配对随机数固定，未挑选有利故障轨迹；
9. 分析路径分叉：六个消融单元和判定方向在运行前固定；
10. 相关替代因果：信念恢复明确标为依赖组效应；
11. 反向因果：学习候选只使用因果历史特征，不读取未来状态。
