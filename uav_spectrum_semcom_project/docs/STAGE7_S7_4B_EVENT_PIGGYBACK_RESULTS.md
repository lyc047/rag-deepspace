## 1. 研究问题

S7.4A周期检查点因周期帧和ACK成本未能形成稳定优势。S7.4B取消独立检查点，只在解析regret或最大年龄本来就会触发任务更新时，将紧凑更新升级为可从预装目录恢复的更新帧，并复用原任务ACK。

该策略是因果的：发送端不知道真实接收端重置事件，也不会为了上下文身份额外制造任务更新。

## 2. 实验设计

基线为固定10景和16景心跳加普通紧凑更新。候选为：

- 12景心跳加事件自包含更新；
- 16景心跳加事件自包含更新；
- 24景心跳加事件自包含更新。

主门槛要求同一个候选至少在3/4种N满足：

- 路径A：总bit降幅95%区间下界不低于5%，clean损失不超过0.5个百分点；
- 或路径B：clean增益95%区间下界不低于1个百分点，总bit增加不超过5%；
- 错误码本动作执行次数必须为0。

## 4. 机制解释

事件更新能够恢复隐藏重置，但每景仅发生约0.0035—0.0044次有效救援。相比之下，码本身份升级增加约2.28—4.90 bit/景。

因此：

- 12景策略保持了相对接近的clean，却因身份开销导致总bit不降反升；
- 16景和24景通过减少心跳获得平均bit收益，但上下文重置等待时间变长，clean损失远超0.5个百分点；
- 三种候选均为0/4种N通过，错误码本动作执行次数均为0。

## 5. 决策

1. 不将事件捎带方案加入冻结主架构；
2. 保留实现与负结果，证明“利用已有任务更新恢复上下文”的机会密度不足；
3. 停止继续增加周期检查点、事件捎带、预测心跳等有状态组件；
4. 不打开内部开发测试集或储备集；
5. 下一步进入S7.4C半无状态帧头审计：比较每次任务帧携带最小码本键的长期成本，与固定心跳、恢复和会话长度之间的解析边界；
6. 若半无状态设计仍不能形成跨N优势，则冻结固定10景心跳作为论文工程边界，不再扩展可靠性协议。

## 6. 统计解释与11项谬误扫描

总体置信度：CAUTION。结果可支持开发分支决策，不能替代新站点外部验证。

- Simpson悖论：四种N分别报告，未用单一规模正结果覆盖总体失败。
- 生态谬误：不将7站点均值推断为具体无人机链路。
- Berkson偏差：开发站点经过既有解析规则筛选，存在代表性限制。
- 碰撞变量偏差：未按候选表现筛选站点或轨迹。
- 基准率忽视：同时报告救援率、clean、bit及开销分解。
- 均值回归：不适用，未选择极端轨迹作为干预组。
- 幸存者偏差：所有轨迹均计入，未解析站点统一精确回退。
- 多重搜索效应：三个候选和四种N全部报告。
- 分叉路径：策略、门槛、随机种子和bootstrap在运行前冻结。
- 相关不等于因果：共同随机数支持协议内受控比较，但不能外推真实故障率。
- 反向因果：不适用于时间有序的协议仿真。
