## 1. 研究问题

本阶段回答：任务容差、信道规模和查询数量变化时，任务等价码本能否继续形成稳定的可靠性—通信开销优势。

不能再把ε＝0.2 dB和K＝3当作固定事实。本阶段需要确定：

1. ε放宽后码本是否变小、escape是否减少；
2. 单查询、双查询和三查询时语义码本的独立收益如何变化；
3. N增加后，精确动作包增长是否转化为真实的端到端语义优势；
4. 把持久码本首次安装成本计入后，需要多长部署寿命才能回收安装开销；
5. 原R1正结果是否能在相同配置下确定性复现。

## 4. 持久码本成本

V2的运行期总开销不包括每景重复安装码本，但不能忽略首次部署成本。因此同时报告：

摊销总bit/景＝运行期bit/景＋码本安装bit ÷ 部署寿命景数。

部署寿命取500、5,000和50,000景。

若精确基线每景开销大于语义运行期开销，则安装成本盈亏平衡景数为：

盈亏平衡景数＝向上取整［码本安装bit ÷（精确bit/景－语义运行期bit/景）］。

若语义运行期开销已经不低于精确基线，则不存在有限盈亏平衡点。

## 6. 预注册决策规则

1. ε＝0.2 dB、三查询配置必须确定性复现R1冻结结果；
2. 三查询条件下，至少三个N需要在五种ε中的至少三种保持matched-clean节省率95%置信下界大于0，才称为较宽rate–risk支持；
3. 单查询到多查询的优势必须通过配对系统结果判断，不能只根据payload宽度推断；
4. 若优势只存在于单一ε或单一N，论文必须收缩适用范围；
5. 表示层bit下降但系统总bit未下降，不通过系统验收；
6. K＝3只作为已观察到的开发现象，不预设为普遍结构；
7. 所有不可部署或负结果网格点必须保留。
