# 阶段4正式论文章节：面向连续频谱块选择的任务导向数字语义与可靠资源决策

> 文档状态：阶段4权威终稿，取代`STAGE4_THESIS_CHAPTER_DRAFT.md`中的Final前占位结论。  
> 证据状态：原三站点Final、C1-v3时域确认和C1-v4双站点跨日期Final均已单次执行；所有访问计数为1。  
> 核心结论：C1-v4两级假设通过；选择性G2在原Final中通过；C2、C3保留为负结果与机制边界。

## 1. 研究问题

多节点宽带频谱感知系统通常先估计各频点是否被占用，再向融合端上传占用概率或硬判决。然而，通信系统最终执行的并不是逐频点分类，而是在有限上报资源下选择一段连续、总体干扰功率尽可能低的频谱。若语义表示只保留“超过阈值的频点比例”，低于阈值但会改变候选频谱块排序的连续功率信息将被永久丢失。与此同时，数字链路的整包失败会让融合端缺少当前资源决策；盲目选择固定默认块或无限复用历史决策，都可能放大尾部风险。

阶段4因此研究三个问题：应发送什么频谱语义才能直接服务连续资源选择；如何在真实数字包成本下处理语义包失败；多节点语义粒度和可靠少数机制是否能够在同一闭环内获得稳定系统收益。研究全过程保留通过和未通过预注册门槛的分支，避免用模型复杂度代替有效性证据。

## 2. 系统与任务模型

考虑将2.4 GHz频段划分为 N = 8 个等宽频道，任务需要选择 D = 4 个连续频道。设一次扫频得到的频道平均接收功率为 p₁，p₂，…，p₈，第 j 个候选连续块的代价为：

> **候选块代价：** cⱼ = (pⱼ + pⱼ₊₁ + … + pⱼ₊D₋₁) ÷ D，其中 j = 1，2，…，N−D+1。

最优决策是代价最小的候选块，即 j* = arg minⱼ cⱼ。若系统实际选择块 ĵ，资源选择后悔值为 R = c_ĵ − c_j* ≥ 0。实验同时评价平均 R、最坏10%场景的 CVaR₀.₉(R)、应用层bit、经过分包、CRC、Hamming(7,4)、调制和有限ARQ后的实际发送bit，以及最终帧成功率。上报链路覆盖AWGN、Rayleigh、Rician和 Eᵦ/N₀ = {0，3，6，9} dB。

## 3. 方法演进与最终算法

### 3.1 从occupancy代理到任务充分块语义

早期C1通过可微资源后悔损失训练occupancy预测头，在开发集上通过Gate A，但原200景三站点Final没有同时通过平均regret、CVaR和bit门槛。随后C1-v3增加尾部排序惩罚，在新的300景时域确认中仍未通过平均和CVaR优势门槛。事后机制分析表明，问题不是网络容量不足，而是监督目标与最终任务错配：二值occupancy无法恢复连续dBm域的块排序。

C1-v4不再预测间接代理，而是构造五个候选连续块的归一化代价，或直接发送最优块指示。对于固定 N = 8、D = 4 的任务，j*是单次资源决策的任务充分统计量。冻结比较包含8维4-bit occupancy、8维4-bit信道功率、5维4-bit块代价、5维6-bit块代价和5维1-bit最优块指示，统一使用152-bit版本化协议开销。开发结果按预注册准入规则选择`best_block_indicator1`，其应用层长度为157 bit；`block_score_fixed4`作为未来多需求或二次规划的较丰富备选表示保留。

### 3.2 带时效保护的零比特接收端回退

最优块语义在无链路错误时几乎消除了映射后悔，剩余损失主要来自CRC可见的整包失败。因此最终算法在接收端为每个站点、每条冻结链路条件流保存最近一次成功解码的块索引及时间戳。当当前包失败且状态年龄不超过60分钟时复用该块；状态不存在或超过60分钟时回到预注册安全默认块0。

该机制不修改报文、不增加反馈、不改变发送bit和成功/失败轨迹。块代价构造复杂度为 O(ND)，最优块搜索为 O(N−D+1)，每站点状态更新和查询为 O(1)。60分钟上限在读取Final测量值前冻结，用来阻止长时间失联后无限复用陈旧决策。

### 3.3 多节点选择性G2及停止分支

原三站点Final中，选择性G2相对all-G2将实际发送bit降低约3.24%，并满足冻结资源后悔非劣门槛，因此作为多节点上报节流正结果保留。但AERPAW站点是固定接收地点，回传仍为仿真，该结果不构成无人机空间协作或MIMO证据。

C2反事实价值网络、解析背包及稀疏残差草图虽揭示oracle改进空间，但部署前可见特征无法稳定辨识候选价值，系统固定开销也抵消局部收益，因此Gate B失败。C3可靠少数和确认补传能够修复部分受控故障，却未同时满足误触发、实际bit与尾部风险门槛，因此Gate C失败并回退经典融合。这两条路线作为可观测性、固定开销和可靠性边界保留，不包装为正性能创新。

## 4. 数据治理与Final协议

C1-v4开发仅使用AERPAW 2月8—12日早期数据，并按整日划分训练、校准和开发验证。Final使用此前从未被工程引用的CC1、CC2站点2月14—15日数据。先按至少15分钟稀疏，再确定性等距选择每站140景，共280景，形成74个“站点×本地小时”重采样簇。全部pilot、原三站Final、C1-v3校准/确认和C1-v4开发provenance永久排除，重叠数为0。

在读取测量值前，研究冻结了精确ZIP成员清单、CRC与大小、157/184-bit报文、60分钟陈旧上限、信道网格、随机种子、20,000次配对分组bootstrap、单侧95%上界和固定顺序假设。67个执行文件形成哈希快照后，访问状态由0原子更新为1。Final完成后算法、阈值和统计程序没有变化，快照复核的变化文件数为0。

固定顺序检验首先测试H1“最优块指示优于occupancy”，要求平均regret、CVaR和实际bit的单侧95%上界均低于0；H1通过后才确认H2“时效保护回退优于无状态回退”，要求平均regret和CVaR上界低于0且实际bit严格相等。每个假设采用交集判决，不因某一个有利指标通过而接受整体假设。

### 5.1 Final后的补充基线解释

为完善经典算法比较，研究在不读取Final测量值或指标的条件下，仅用已见开发缓存增加硬能量判决、4/8-bit软功率、零通信参考、不同ARQ次数及无限状态保持基线。该实验属于解释性补充，不参与算法选择，也不改变上述单次Final结论。

在180景表示开发集上，最优块指示相对硬能量判决将平均regret/CVaR降低63.50%/66.35%；相对4-bit软功率仅进一步降低2.42%/2.42%，但实际发送bit降低8.46%。这表明从硬判决或occupancy到连续软信息产生主要精度收益，而本文方法相对软信息的核心优势是任务充分压缩。8-bit软功率因报文更长、整包成功率更低，没有优于4-bit软功率。

在另一180景时序开发集上，60分钟保护相对标准ARQ无状态回退将平均regret/CVaR降低19.43%/28.63%，实际bit不变；相对额外ARQ，其平均regret无显著优势，但CVaR低9.10%、实际bit低18.00%。无限保持在固定站点慢变化数据上比60分钟保护更好，说明年龄上限是防止长失联陈旧状态的保守安全约束，而非该数据上的纯性能最优值。完整定义、统计结果和负结果见[补充基线报告](STAGE4_C1_V4_SUPPLEMENTARY_BASELINES.md)。

### 5.2 频谱维度扩展实验

进一步在同一已见开发日期的180个扫频上，将频谱重新划分为N = {8，16，32，64}，并测试D/N = {0.25，0.50，0.75}。该实验不读取Final，仅用于验证表示的规模增长规律。相对每信道4-bit软功率，当前最优块独热指示在全部N=32和N=64任务中同时满足“实际bit降低至少20%且平均regret单侧95%上界非劣”；共6/12个任务达到该强目标。

当N=64时，独热指示在三个需求比例下将实际发送bit降低39.98%～46.26%。N=64、D=32时，软功率、独热指示和开发性二进制块编号的实际bit分别为1362.81、775.29和689.78，平均regret分别为0.286245、0.250619和0.244000 dB。在AWGN 3 dB的包成功率过渡区，三者平均regret分别为0.3974、0.2178和0.1847 dB，说明较短任务报文可减缓中低信噪比区的退化。二进制编号是Final后的协议增强，仅作为开发结果，不列为已确认Final贡献。完整实验见[规模可扩展性报告](STAGE4_C1_V4_SCALABILITY_EXPERIMENT.md)。

## 6. 创新点与论文贡献

第一，提出面向连续频谱块选择的任务充分数字语义。与阈值occupancy不同，该表示直接对齐最终离散资源决策，并在真实应用层和链路bit账本下同时改善决策精度、尾部风险和通信成本。

第二，提出带最大陈旧时间的零比特接收端状态回退。它将成功解码的历史资源决策作为接收端语义状态，在不修改报文与链路轨迹的条件下保护整包失败场景，并通过年龄上限控制状态过时风险。

第三，建立可审计的任务—通信联合评价和单次验证流程。所有方案经同一数字codec、FEC/ARQ、实际发送bit和资源后悔指标评价；相邻扫频按时间簇重采样；正负结果、访问回执、快照和来源哈希完整保留。

选择性G2可作为补充系统贡献：在原三站点Final中保持任务非劣并减少实际上报bit。C2、C3不列为正向算法贡献，而作为“可预测价值受限于预发送可观测性”和“可靠性机制受误触发及固定开销约束”的实证发现。

## 7. 局限性

Final数据来自同一AERPAW 2022年2月活动，虽与开发日期完全隔离，但不是跨数据集或跨采集活动验证。站点固定，不含无人机运动和动态拓扑；输入是`rf32_le`接收功率扫频，不是复数原始I/Q；上报链路是冻结仿真而非实测空口；任务固定为8频道中选择连续4频道；系统没有显式多天线信道矩阵、预编码或联合收发，因此不是MIMO算法。

新的公开数据集、新采集批次或目标硬件实验可以增强外部效度和工程部署结论，但不是对本次Final的重跑，也不得用于改写已经消费的单次检验。

## 8. 本章结论

阶段4最终形成一条由失败机制推动、并经一次性跨日期Final确认的算法主线：早期occupancy学习方法在外部检验中暴露目标代理错配；C1-v3证明单纯增加尾部权重不能恢复被阈值化丢失的信息；C1-v4转而发送资源决策所需的任务充分块语义，并以带陈旧保护的零比特状态回退处理数字包失败。最终结果表明，完整方法在降低实际通信成本的同时显著改善平均资源后悔和尾部风险，两个预注册假设均成立。选择性G2提供补充节流证据，C2和C3则清晰界定了当前方法的可观测性与可靠性边界。
