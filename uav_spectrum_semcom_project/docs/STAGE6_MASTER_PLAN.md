## 1. 研究定位

阶段五冻结为工程基线，不修改既有结果和Final协议。阶段六研究对象从“发送每个查询的精确最优块索引”升级为“发送能够满足多查询任务损失约束的频谱语义码字”。

对频谱状态x、查询q和候选动作a，任务regret定义为：

R(x,q,a) = c(x,q,a) − minₐ′ c(x,q,a′)

其中c表示候选连续频谱块的平均功率代价，单位为dB。若一个码字对应的解码动作在全部冻结查询上均满足：

R(x,q,a) ≤ ε

则该频谱状态可由该码字安全表示。第一版固定ε = 0.2 dB，与阶段五事件触发风险上限保持一致，不根据本轮结果调整。

### 自主执行约定

在既定阶段六研究主线内，局部算法实现、预注册开发实验、负结果记录、测试修复、参数冻结和文档更新均自主连续执行，不逐项请求确认。只有出现以下重大变化时暂停并向用户汇报：

- 需要访问或消耗外部Final；
- 需要下载新的大规模数据或明显增加存储、计算成本；
- 需要改变论文核心研究问题或从频谱资源主线转向图像、多模态等新主线；
- 新证据可能推翻已冻结的阶段四、阶段五或阶段六核心结论；
- 需要执行不可逆操作或扩大数据、设备和外部系统权限。

## 6. 阶段六总体成功标准

阶段六需至少满足一项，并且regret风险不劣于阶段五：

- 相同风险约束下，应用层总比特相对阶段五精确查询包降低10%以上；
- 相同总比特下，平均regret或CVaR₀.₉(R)降低10%以上；
- 支持阶段五无法直接表达的新任务约束，并保持最大regret不超过冻结上限；
- 学习型方法相对解析码本取得稳定、可重复且具有实际意义的增益。

同一活动内的开发结果只能用于算法筛选，不得写成跨活动泛化结论。
