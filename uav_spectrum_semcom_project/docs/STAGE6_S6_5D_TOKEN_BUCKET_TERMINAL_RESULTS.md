## 1. 研究目的

S6.5c发现离散马尔可夫分数会产生29至47个预约候选，而系统只有17次容量，可能导致预算在序列前部耗尽。S6.5d引入因果token bucket，使容量随时间逐步释放：

- 每个场景增加0.1个令牌；
- 桶容量为2；
- 每个时间簇初始1个令牌；
- 候选只有在分数超过训练阈值且令牌至少为1时才能预约；
- 不读取未来分数、未来候选数或评估序列全局排名。

本实验在协议中预先声明为马尔可夫控制器的终止性实验。

token bucket在四种N上均产生正clean rate点估计，但代价效率：

- 只在N = 64上高于未整形马尔可夫，门槛为至少3种N；
- 在0/4种N上达到冻结学习风险排序，门槛为至少3种N；
- 因而未通过保留标准。

token bucket确实降低了部分预约容量，但同时过滤掉了过多有效保护机会。降低预约数量本身不是成功，必须同时维持单位资源可靠性收益。

## 3. 终止决策

按照预注册失败动作：

- token bucket马尔可夫调度器不保留；
- 马尔可夫控制器优化正式终止，不继续调整令牌速率、桶容量、初始令牌或阈值；
- 一阶马尔可夫仅保留为可解释的预测基线；
- 持续时间和熵可用于解释或消融，但不进入最终控制器；
- 当前保留的预测性控制仍为S6.4c学习风险排序驱动的更新重复保护；
- 预测结果继续禁止直接执行信道动作。

这不是“马尔可夫完全无效”。它能够预测频谱语义状态转移，但没有在受限通信容量下超过任务风险学习方法。论文中应将其作为“预测准确率不等于闭环效用”的完整负结果。

## 4. 统计解释

总体置信等级为 **CAUTION**：

- N = 8的增益接近0，实际意义很小；
- N = 16和32区间高于0，但效率明显低于两个强基线；
- N = 64相对未整形方法改善，却仍略低于学习风险排序；
- CVaR₀.₉在所有N上均没有变化；
- 结果来自同一排除型固定站点开发活动，不能作为跨活动或真实无人机移动链路证据。

## 5. 11项谬误扫描

覆盖11/11项：

1. 辛普森悖论：四种N的token增益同向为正，但相对未整形方法只有N = 64占优；不以总体平均宣称成功。
2. 生态谬误：不从频谱时间簇推断单架无人机行为。
3. Berkson偏差：固定站点pilot是选择性开发样本，标记CAUTION。
4. 碰撞变量偏差：没有按预约成功或恢复结果筛选样本。
5. 基准率忽视：同时报告绝对增益、预约容量和单位bit收益。
6. 均值回归：没有按极端N或极端轨迹选择样本。
7. 幸存者偏差：60条轨迹全部纳入。
8. 遍历效应：token参数只有一个预注册组合，没有从参数网格挑选最好结果。
9. 分析路径分叉：失败动作在运行前冻结，失败后未继续调参。
10. 相关代替因果：只允许在受控模拟器内解释token策略的配对差异。
11. 反向因果：令牌状态只由当前及过去候选更新，不读取未来。
