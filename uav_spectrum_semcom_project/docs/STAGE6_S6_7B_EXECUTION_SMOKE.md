## 1. 本次新增内容

新增的S6.7b执行层没有修改S6-FC0锁定文件，而是在新版本文件中实现：

1. 预配置码本、接收端动作为空的会话起点；
2. 在线安装码本、接收端上下文为空的会话起点；
3. 语义更新1、2、3次独立开环发送；
4. 自包含精确动作包1、2、3次独立开环发送；
5. 两种方法共享的11条固定用途随机流；
6. 前向、反馈、安装、恢复、心跳、escape、重复和预留容量的逐项记账。

K次任务发送严格复用前K条任务丢包随机流。因此，K = 1、2、3之间是配对关系，增加尝试次数不会因为更换随机样本而虚假改变结果。

## 4. 运行成本

实测：

- 1,700次scene评估耗时约0.144秒；
- 单进程吞吐量约11,771次scene评估/秒；
- 计入三种会话长度后，完整粗网格上界预计95,135,040次scene评估；

该估计没有包括2022三站点的流式解析和分组验证，因此完整阶段耗时会更长。粗网格应支持分批输出和断点恢复，避免一次进程失败导致全部重跑。
