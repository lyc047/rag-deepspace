# 阶段 3：LoRaIQ 真实四接收机小样本实验结论

## 实验定位

本实验首次使用同一次无人机 LoRa 发射在 4 个真实 RRH 上的对齐 I/Q，而不是对一条记录人为构造 4 条感知信道。当前只下载了 2 次发射：LoS `27429` 与 NLoS `23039`，因此实验用于验证真实多接收机端到端接口和发现失效机制，不作为正式 H3 统计检验。

每个节点从 `cf32_le` I/Q 中计算 4 个等宽子信道的帧内/帧外 Welch 功率增量，形成 4 个 8 bit 量化占用概率。单份应用语义为 241 bit；随后统一经过阶段 2 的 QPSK/AWGN、96 bit 链路头、CRC-16、Hamming(7,4)、字节填充和最多一次重传。所有方法使用相同节点报告和链路实现。

## 真实节点差异

LoS 事件中，4 个 RRH 的标注 SNR 为 `44.10/14.73/15.34/5.16 dB`，本地信道级 F1 为 `0.667/0.800/0.800/1.000`。最高 SNR 的 RRH1 出现全频带泄漏或前端饱和式响应，说明 SNR 高不等于占用估计一定正确。

NLoS 事件中，4 个 RRH 的 SNR 为 `-20.21/-13.69/-0.18/-16.55 dB`。只有 RRH3 检出中心占用，本地 F1 为 1；其余 3 个节点 F1 均为 0。这构成“单个可靠节点与多数低质量节点不一致”的真实失效场景。

## 端到端结果

20 次重复只改变数字上报链路随机性，不增加独立感知事件。主要均值如下：

| 方法 | F1 | Brier | 上行 bit/decision | 调度反馈 bit | 链路时延 |
|---|---:|---:|---:|---:|---:|
| 动态最佳单节点 | 0.8889 | 0.0948 | 630.0 | 0 | 1.36 ms |
| 全节点等权平均 | 0.5417 | 0.1848 | 2803.5 | 0 | 1.98 ms |
| 全节点 SNR 加权 | 0.8500 | 0.1124 | 2803.5 | 0 | 1.98 ms |
| 全节点鲁棒质量加权 | 0.6161 | 0.1380 | 2803.5 | 0 | 1.98 ms |
| 所提自适应价值/bit | 0.7500 | 0.1233 | 1890.0 | 96 | 4.05 ms |

所提方案相对全节点上报节省约 32.6% 上行 bit 和参考 RF 发射能量，但 ACK/候补串行过程使链路时延增加约 104.6%。其 F1 高于全节点等权平均和全节点鲁棒质量加权，但低于全节点 SNR 加权及动态最佳单节点，不能宣称当前方法最优。

## 关键困难与结论边界

当前鲁棒一致性门控在 NLoS 事件中会压制唯一正确的 RRH3，因为另外 3 个低 SNR 节点形成了错误多数。这表明“一致性”不能脱离节点可检测性和元数据可信度使用。后续应研究“可靠少数保护”或基于不确定性的混合门控，而不是继续增强多数一致性权重。

两个事件都只占用中心半带，所有策略的 clean rate 均为 1，regret 均约为 0.003，资源选择任务已经饱和，无法区分融合策略。检测阈值也在这两个 pilot 事件上检查过，不是独立冻结测试阈值。因此，本实验只证明真实同源四接收机 I/Q 已成功接入“本地感知—量化语义—公平数字链路—节点选择—融合—资源选择”闭环；它不证明多 UAV 接收、不证明宽带多占用泛化，也不建立 H3。

## 下一步

1. 从 LoRaIQ 按完整飞行/采集批次划分 train、validation 和 holdout，避免同一飞行相邻帧泄漏；
2. 先在 validation 冻结 Welch 阈值、温度和节点策略，再一次性评估数百至数千个 holdout 发射；
3. 增加节点数、LoS/NLoS、SNR 异质性及节点失效 sweep，并按独立发射事件计算置信区间；
4. 将真实多接收机融合证据与 POWDER/RadDet 的多占用宽带资源任务分开报告；
5. 增加“单个高可信节点保护”和不确定性感知回退，与 SNR 加权和最佳单节点强基线比较。
