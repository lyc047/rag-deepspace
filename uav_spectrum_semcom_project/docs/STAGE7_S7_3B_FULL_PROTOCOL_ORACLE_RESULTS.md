## 1. 研究目的

S7.3a发现提前刷新标签具有一定反事实价值，但验证正事件高度集中于EDLV。S7.3b不训练模型，而是给予系统一个更有利的非因果条件：

> 系统预先知道未来10景中哪些时刻安排一次刷新能够减少不洁净景，然后在下一景使用当时实测频谱发送正常语义更新。

如果这种预言机在完整可靠性协议中仍不能改善clean–bit前沿，就没有理由继续增加预测模型复杂度或为该分支消费内部测试集。

## 2. 完整协议条件

比较5种策略：

1. 固定6景静默心跳；
2. 冻结基线固定10景心跳；
3. 固定16景心跳；
4. 固定10景心跳加非因果强制刷新；
5. 固定16景心跳加非因果强制刷新。

除心跳间隔和是否接入预言机外，其余均使用冻结阶段6R工作点，并完整模拟：

- 任务帧丢失和开放环重复；
- ACK丢失与延迟重复ACK；
- 接收端上下文重置；
- 预安装码本激活与失败后的完整安装；
- 解析信念、最大状态年龄、regret触发；
- escape精确动作回退；
- 前向、反馈、心跳、恢复和ACK全部应用层bit。

预言机只要求“发送一次正常更新”，不能绕过丢包、上下文、身份、码本或fail-closed检查。

固定6景则能相对固定10景提高1.65—2.54个百分点clean，但会增加19.00%—27.57%总bit。这说明当前系统仍存在明确的可靠性—开销权衡，却没有形成被任务预测支配的新Pareto点。

## 5. 决策结论

S7.3b为0/4种N通过，错误码本动作执行次数全部为0。研究结论为：

1. 停止“用频谱任务预测调度强制刷新或替代心跳”的分支；
2. 不训练更复杂的梯度提升树、GRU、TCN、Transformer或GNN；
3. 不打开内部开发测试集或储备站点；
4. S7.3a的事件分解可保留为标签分析成果，但不升级为主算法；
5. 阶段7下一入口转为解析型上下文可靠性和周期自包含协议。

该负结果不否定整个任务语义系统。它说明频谱变化风险与接收端随机上下文丢失是两个不同问题：

- 频谱变化已经被当前regret触发较充分地覆盖；
- 随机重置不可由频谱历史预测，必须由心跳、上下文摘要或自包含帧直接处理。

## 6. 下一阶段：S7.4A解析上下文协议

下一阶段不使用AI，围绕“怎样以较少状态维护开销发现或容忍上下文丢失”开展：

1. 建立固定心跳的更新过程模型，分解重置检测时延、恢复bit和不洁净突发长度；
2. 设计周期自包含关键帧：每H景发送一次包含码本身份、纪元和动作的可独立解码帧，其余场景使用紧凑有状态更新；
3. 设计上下文摘要捎带：只在已有任务更新上捎带短摘要，不单独增加高频ACK；
4. 比较 H ∈ {6，8，10，12，16}，不根据单一N选择；
5. 与固定6/10/16景、纯无状态精确动作和现有有状态协议比较；
6. 主判断仍为相同clean下总bit是否至少降低5%，或相同总bit下clean是否提高1个百分点；
7. 所有候选继续要求错误上下文动作执行次数为0。

只有在获得真实重置或ACK时间序列后，才考虑在线估计重置危险率；当前不使用频谱特征预测独立重置。

## 7. 统计解释与11项谬误扫描

总体置信度：CAUTION。

- Simpson悖论：已同时使用站点优先分层bootstrap和四种N分别报告；仍需注意EDLV事件集中。
- 生态谬误：不把7站点平均结果推断为任一具体无人机链路。
- Berkson偏差：存在注意项；站点须通过冻结解析规则，不能代表所有无线环境。
- 碰撞变量偏差：没有按预言机结果筛选站点或轨迹。
- 基准率忽视：同时报告clean、总bit、触发重复率和错误动作。
- 均值回归：不适用；没有按极端故障轨迹选取干预组。
- 幸存者偏差：未删除失败轨迹；未解析站点按精确回退计入所有策略。
- 多重搜索效应：5种策略和4种N均已预注册，整体0/4结论完整保留。
- 分叉路径：协议、随机种子、轨迹数、bootstrap和门槛在运行前冻结。
- 相关不等于因果：策略使用共同随机数受控比较，可解释协议差异；不能推广到真实无人机故障率。
- 反向因果：不适用于受控、时间有序的策略比较。

覆盖：11/11。
