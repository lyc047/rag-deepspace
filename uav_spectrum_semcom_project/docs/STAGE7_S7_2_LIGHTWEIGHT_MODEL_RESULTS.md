## 1. 研究目的

S7.1表明动作持续时间和码字转移包含未来任务失效信息，但聚合AUC受站点风险差异影响。S7.2检验：

> 加入完整因果频谱、regret、次优间隔和语义状态特征后，正则化逻辑回归或离散时间生存模型能否稳定提高同一站点内部的风险排序，同时保持可用的校准、召回率和告警开销。

本阶段没有读取内部开发测试集，也没有将站点身份作为模型特征。

## 2. 模型与冻结协议

输入包括21个连续特征和3个离散特征：

- 当前功率分布、相邻信道差异；
- 当前与历史功率变化；
- 上一动作regret和是否越界；
- 动作变化比例与持续时间；
- 当前码本动作、fallback和regret；
- 各查询的次优间隔和动作regret；
- 当前码字、上一时刻码字和动作持续时间分箱。

比较四种模型：

1. 未加权直接逻辑回归；
2. 类别平衡直接逻辑回归；
3. 未加权离散时间生存逻辑回归；
4. 类别平衡离散时间生存逻辑回归。

离散时间模型首先预测第1至10景的条件失效概率 λₖ，再计算累计风险：

`P(T ≤ h) = 1 − ∏ₖ₌₁ʰ (1 − λₖ)`

其中T是当前动作首次超过0.2 dB任务容差的未来景数。

正则化强度 C ∈ {0.03，0.1，0.3，1.0}，只通过训练站点5折分组交叉验证选择。告警阈值也只由训练集分组交叉预测确定，目标召回率为0.8。

## 4. 各模型的行为

### 4.1 未加权直接逻辑回归

这是总体最稳定的学习模型：

- 四种N的Brier skill均为正；
- ECE为0.017—0.045；
- N = 16/32满足召回和告警约束；
- 但不能超过持续时间/Markov查表基线。

这说明完整线性特征可以得到合理概率，但没有产生额外的稳定站内排序信息。

### 4.2 类别平衡逻辑回归

类别平衡没有解决稀有事件问题，反而改变了概率尺度：

- N = 16的ECE升至0.162，Brier skill降至−0.466；
- N = 8的ECE为0.077，性能仍未超过未加权模型；
- N = 32/64也没有形成站内AUC优势。

因此，“提高少数类权重”不能自动等同于“提高可部署风险预测能力”。

### 4.3 离散时间生存模型

未加权生存模型只在N = 8被验证集选中，但告警比例达到35.8%。其余N的站内宏AUC低于直接逻辑回归。

原因是当前每个源场景在未来10景内使用相同的时刻t特征，模型只能学习固定基线危险率随时间变化，不能观察未来时变协变量。动作持续时间查表已经直接捕捉了主要的半Markov结构，因此更复杂的累计危险率表达没有带来新增信息。

## 5. 负结论的研究价值

本阶段支持以下结论：

1. 任务风险确实具有可预测结构，但主要结构是动作持续时间和离散码字转移；
2. 在当前数据和标签下，加入完整线性频谱特征没有稳定超过简单强基线；
3. 类别平衡训练明显损害概率校准，不适合直接驱动可靠性预算；
4. 生存建模的形式复杂度不会自动转化为系统收益；
5. 当前不具备打开内部测试集或升级GRU、TCN、Transformer的依据。

这不是“阶段7没有成果”，而是确定了一个重要边界：当前主要问题不在模型容量不足，而在预测标签与协议控制目标之间仍有距离。

## 6. 下一研究入口

按照运行前冻结的决策规则，下一步停止模型复杂度升级，转入S7.3“任务事件与协议价值标签重构”：

1. 把单次超阈值事件拆分为瞬时失效和持续失效，避免一次功率抖动与真正需要更新被同等处理；
2. 构造“提前保护是否有净收益”的标签，而不是只预测未来是否失效；
3. 标签同时计入避免的clean损失、额外重复或心跳bit以及错误告警代价；
4. 将独立接收端重置继续交给解析信念，不与频谱任务风险混合训练；
5. 先用S7.1持续时间基线测试新标签是否具有跨站点稳定性；
6. 只有当新标签在训练—验证站点上形成稳定结构时，才重新考虑梯度提升树；
7. 内部开发测试集继续封存。

一个可执行的保护价值可写成：

`Vprotect(t) = Lfixed10(t) − Lprotected(t) − λ × ΔB(t)`

其中L表示由不可用、超任务容差和错误上下文造成的任务损失，ΔB是增加的控制bit，λ是单位bit代价。后续模型应预测Vprotect是否为正，而不是仅预测“未来可能有一次regret越界”。

## 7. 统计解释与11项谬误扫描

总体置信度：CAUTION。

- Simpson悖论：已控制。冻结判断使用站点内宏AUC，并单独报告EDLV，不以聚合AUC代替站内性能。
- 生态谬误：未将站点平均关系推断为单个设备故障机制。
- Berkson偏差：仍存在注意项；未通过语义上下文解析的站点未进入模型。
- 碰撞变量偏差：未作因果效应估计，暂未发现明显碰撞控制变量。
- 基准率忽视：同时报告发生率相关的AP、Brier、ECE、召回率和告警比例；不只报告AUC。
- 均值回归：不适用，没有按极端模型结果选择干预组。
- 幸存者偏差：存在注意项；不同N只有5—6个已解析验证站点，不能推广到全部站点。
- 多重搜索效应：存在注意项；比较了4种模型、4个C和4种N，结果属于开发选择，不作显著性宣称。
- 分叉路径：已降低；模型、C网格、分组方式和门槛均在运行前登记。
- 相关不等于因果：已控制；只能说特征与未来失效相关，不能解释为导致失效。
- 反向因果：时间顺序明确，但共同环境可能同时影响当前特征与未来标签。

覆盖：11/11。
