# Phase 1 Baseline Report: Real SigMF I/Q

## 1. 数据概况

- 数据源：短 5G NR SigMF 真实 I/Q 录制
- 样本数：1,100,272
- 时长：0.143265 s
- 采样率：7.680 MHz
- 中心频率：1876.954 MHz
- 参与评估的标注数：55

## 2. 最佳传统 baseline

- 检测增强方式：`freq_median`
- 阈值 sigma：7.0
- 最小连通域单元数：16
- 预测框数：45
- Precision：0.6667
- Recall：0.5455
- F1：0.6000
- 平均匹配 IoU：0.2170
- 最佳 IoU：0.6054

## 3. 传输开销对比

| 方案 | 等效速率 | 说明 |
|---|---:|---|
| 原始 32+32 bit I/Q | 491.520 Mbps | SigMF 原始量化格式估计 |
| 重量化 12+12 bit I/Q | 184.320 Mbps | 常见 SDR 量化位宽估计 |
| 8-bit STFT | 245.535 Mbps | 直接上传时频图仍然很贵 |
| 语义候选框包 | 26.587 kbps | 当前 baseline 的候选框 payload |

## 5. 当前结论

1. 真实 I/Q 的传输瓶颈非常明显：即使是 7.68 MHz 的短录制，完整 I/Q 的等效速率也达到百 Mbps 量级。
2. 简单语义候选框 payload 只有 kbps 量级，说明任务语义压缩具有很大的通信节省空间。
3. 频率方向背景归一化 `freq_median` 显著提高了召回率，说明弱小同步/控制结构不能只靠原始能量阈值检测。
4. 当前传统 baseline 仍存在频率边界偏宽和漏检 CSI-RS 的问题，后续需要引入更细粒度的时频特征或轻量学习式检测器。

## 6. 下一步

- 构建轻量 STFT-CNN 检测器，先做二分类占用/候选区域热力图，不直接上复杂 Transformer。
- 保持相同 bit 账本，与当前传统 baseline 公平比较。
- 增加硬判决、软信息、语义候选框三种 payload 方案的统一比较。
