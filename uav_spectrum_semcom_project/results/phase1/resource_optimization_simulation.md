# Spectrum Resource Optimization Simulation

## Setup

- Dataset: RadDet40k128HW001Tv2 `test` split, 1000 frames.
- Multi-UAV pressure: 4 UAV observations are fused per decision step, 1000 decision steps.
- Candidate channels: 4, generated by splitting normalized `y` axis.
- Transmission demand: contiguous block of 2 channel(s).
- Decision rule: choose the contiguous resource block with minimum sensed occupancy.
- Clean channel threshold: true occupancy <= 0.02.
- Low-interference threshold: true occupancy <= 0.1.
- Switch cost: 0.005 normalized utility per resource change.

## Interpretation

This experiment closes the loop from spectrum semantic extraction to a resource decision. The current detector is not yet a high-accuracy classifier, so the resource-optimization metric focuses on whether the semantic occupancy report can help avoid occupied channels under limited link budget. Semantic repetition is expected to be useful when packet erasure exists because it keeps the decision input available while remaining far smaller than full spectrogram or I/Q forwarding.
