# 离散任务导向频谱语义通信与可靠资源选择

本项目研究在控制链路丢包、ACK丢失和接收端动作状态可能重置的条件下，如何以较低通信开销维持连续频谱块选择任务。系统不恢复完整频谱，而是根据任务regret构造可接受动作集合，将多个频谱状态映射为可共享的离散任务码字，并通过事件触发、状态复用、上下文校验和精确动作回退保证安全执行。

## 核心方法

对频谱状态x和资源需求q，首先计算候选连续频谱块的任务代价。动作a相对精确最优动作的损失记为regret：

R(x,q,a)＝动作a的任务代价－当前最优任务代价。

给定任务容差ε，只要动作满足：

所有查询中的最大regret ≤ ε，

就认为该动作对当前任务可接受。多个不同频谱状态可以共享同一动作码字；无法安全覆盖的状态使用escape加精确动作回退。

当前R1 V2协议把状态分为：

- 持久码本：保存在非易失存储或稳定固件中；
- 易失动作缓存：普通接收端重置后允许丢失；
- 紧凑刷新：动作失效或缓存重置时发送任务码字；
- 安全回退：码本身份不一致时拒绝紧凑解码。
